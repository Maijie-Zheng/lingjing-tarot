## 一、项目名称

**灵境**

寓意"心灵之境"——既是用户自我探索的入口，也融合了 AI（灵）与人文关怀（境）。

---

## 二、项目背景

塔罗内容在短视频平台（抖音、B站、小红书）持续火爆。典型形式是：塔罗师说出星座、月份、身份等标签，用户自行"对号入座"后观看解读。这种机制配合正向、讨好性的解读，天然获得高流量。

这种现象背后是当代年轻人的普遍心理：面对感情、事业、学业的不确定性时，通过玄学获取**情绪价值和确定感**。用户倾向于选择性相信有利的部分，这让塔罗内容具有天然高粘性。

**传统塔罗内容的局限：**

| 痛点 | 说明 |
|------|------|
| 被动匹配 | 用户等待标签"对号入座"，缺乏参与感 |
| 解读泛化 | 内容面向大众，难以贴合个人真实问题 |
| 真人门槛高 | 一对一塔罗师咨询费用不低 |

**AI 的机会：** 让用户自己抽牌、AI 进行个性化解读——保留仪式感的同时，解决真人的成本和泛化问题。

## 三、目标用户

| 维度 | 描述 |
|------|------|
| 年龄范围 | 12–30 岁（覆盖中学生到年轻职场人，需市场调研验证） |
| 性别 | 以女性为主（需市场调研验证） |
| 典型场景 | 刷短视频时 / 刷朋友圈或微信小程序时 |
| 对 AI 的态度 | 愿意接受（自己抽牌比被动匹配更有参与感和可信度） |

---

## 四、用户痛点

```
心事/困难 → 不确定感 → 焦虑 → 寻求塔罗 → 获得正向解读 → 情绪缓解
```

- 😰 面对感情 / 事业 / 学业的抉择与困难，缺乏确定感
- 📱 刷塔罗视频是被动等匹配，参与感弱，解读泛化
- 💰 真人塔罗师咨询费用较高
- 🗣️ 需要一个"懂心事"的声音，而非泛泛的吉利话

## 五、产品目标

### 用户价值目标（按优先级排序）

| 优先级 | 情绪体验 | 含义 |
|--------|---------|------|
| **B** | 被理解 | AI 真的读懂了用户的心事，解读贴合具体问题 |
| **C** | 有意思 | 好玩、有仪式感、愿意再试 |
| **D** | 被鼓励 | 获得可落地的行动建议，而不仅仅是"结果" |
| **A** | 心里踏实 | 焦虑感降低，获得确定感 |

## 六、产品路线图

| 阶段 | 功能范围 | 核心验证问题 |
|------|---------|-------------|
| **V1（MVP）** | 抽牌 + AI 解读 + 行动建议 + 分享 | 用户觉得 AI 解读"懂自己"吗？ |
| **V2** | 登录/注册 + 星座系统 | 用户愿意注册吗？星座能提升留存吗？ |
| **V3** | 复杂牌阵 + 付费 | 用户愿意为更深的解读付费吗？ |
| **V4** | 社区 | 用户之间会互动吗？ |

> MVP 边界为当前最佳估计，后续各阶段可根据调研与测试结果调整。
