## 一、PM 为什么要做原型？

PRD 用文字描述产品，原型用**画面**描述产品。文字有一个致命问题：

> 10 个人读同一段 PRD，脑子里会浮现 10 个不同的产品。

原型解决的就是这个问题——**让所有人看到同一张图**。

### 原型的三层境界

| 层级 | 叫什么 | 长什么样 | 什么时候用 |
|------|--------|---------|----------|
| L1 | **线框图** | 黑白灰、方块占位、无配色 | 自己快速推演流程 |
| L2 | **高保真原型** | 真实配色、文案、接近最终效果 | 给开发看、给用户测试 |
| L3 | **可交互原型** | L2 + 可点击跳转、动效预览 | 用户测试、投资人 Demo |

**灵境 MVP 建议做到 L2（高保真原型），关键页面（翻牌）做到 L3（加动效说明）。**

## 三、灵境设计系统（Design System）

在画任何一个页面前，先把设计"零件"定好——这能确保 5 个页面看起来是同一个产品。

### 3.1 色彩系统

```
┌─────────────────────────────────┐
│ 深色背景（主背景色）              │
│ #1a0a2e  深紫黑                  │  ← 首页/洗牌/解读页背景
│ #0d0221  更深的紫黑               │  ← 渐变底层
│                                  │
│ 品牌色                           │
│ #c9a96e  灵境金                  │  ← 主按钮、分隔线、高亮文字
│ #8b5cf6  灵境紫                  │  ← 辅助色、hover、选中态
│                                  │
│ 文字色                           │
│ rgba(255,255,255,0.90)  正文     │
│ rgba(255,255,255,0.60)  次要文字  │
│ rgba(255,255,255,0.35)  辅助文字  │
│                                  │
│ 功能色                           │
│ #ef4444  危险/删除               │
│ #22c55e  成功/确认               │
└─────────────────────────────────┘
```

### 3.2 字体系统

```
标题字体：Noto Serif SC（衬线体，有"塔罗感"）
  - 首页大标题：32px / font-weight 700
  - 页面标题：24px / font-weight 600
  - 卡片标题：18px / font-weight 600

正文字体：PingFang SC / Noto Sans SC（无衬线，保证可读性）
  - 正文：16px / line-height 1.8
  - 辅助文字：14px
  - 小字/隐私提示：12px
```

### 3.3 间距系统

```
页面水平 padding：20px（移动端标准安全区）
卡片间距：16px
段落间距：24px
元素内间距：8px（紧）/ 12px（松）
```

### 3.4 圆角 & 阴影

```
卡片/按钮圆角：12px
输入框圆角：8px
chip 标签圆角：20px（胶囊形）

发光效果（选中态）：
  box-shadow: 0 0 20px rgba(201,169,110,0.6)

卡片阴影：
  box-shadow: 0 4px 24px rgba(0,0,0,0.3)
```

### 3.5 通用组件

| 组件 | 用途 | 规格 |
|------|------|------|
| **主按钮** | 核心 CTA | 紫色渐变背景、金色文字、44px 高度、全宽或固定 280px 居中 |
| **次按钮** | 辅助操作 | 透明背景、金色边框、44px 高度 |
| **文字链接** | 次级导航 | 金色文字、无边框、hover 下划线 |
| **牌面卡片** | 塔罗牌展示 | 2:3 宽高比、圆角 8px、微阴影 |
| **Chip 标签** | 问题示例 | 胶囊形、半透金色背景 |

### 4.1 首页

#### 设计目标
> 3 秒内传达"神秘、温暖、值得尝试"的情绪。让用户有冲动点"开始抽牌"。

#### 视觉层次

```
层级 1（最抓眼球）：主视觉牌面 — 一张精美的塔罗牌在屏幕中央缓慢浮动
层级 2（品牌认知）：产品名"灵境" + 副标题"AI 塔罗 · 心灵之境"
层级 3（行动召唤）：金色/紫色渐变的大按钮"✨ 开始抽牌"
层级 4（辅助入口）：右上角小小的"📜 历史记录"文字链接
```

#### 布局标注

```
┌──────────────────────────────────┐  移动端 375×812（iPhone X 标准）
│                                  │
│  📜 历史记录              12px   │  ← 右上角，14px 金色文字
│                                  │
│                                  │
│          ┌──────────┐            │
│          │          │            │
│          │  🃏      │            │  主视觉牌面（The Star）
│          │  牌面插图 │            │  尺寸：140×210px
│          │          │            │  居中，上下浮动动画
│          │          │            │  3s 循环，±10px
│          └──────────┘            │
│                                  │
│          灵   境                 │  32px 衬线体，金色 #c9a96e
│       AI 塔罗 · 心灵之境          │  14px，金色 60% 透明度
│                                  │
│                                  │
│     ┌────────────────────┐       │
│     │   ✨ 开始抽牌        │       │  主按钮 280×48px
│     └────────────────────┘       │  紫色渐变 + 金色文字
│                                  │
│     让塔罗倾听你的心事            │  12px，白色 35% 透明度
│                                  │
│  （星空粒子缓慢飘动，约 30-50 颗）  │  CSS animation
└──────────────────────────────────┘
```

#### 动效说明

| 元素 | 动效 | 参数 |
|------|------|------|
| 星空背景 | 粒子缓慢上升飘动 | 每颗粒子随机速度 20-40s 从底部到顶部，循环 |
| 主视觉牌面 | 缓慢上下浮动 | translateY ±10px，3s ease-in-out 循环 |
| 主视觉牌面 | 极其缓慢的微旋转 | rotate ±2°，5s ease-in-out 循环 |
| 主按钮 | 呼吸光效 | box-shadow 金色 glow，0→60%→0 opacity，2s 循环 |
| 进入页面 | 整体 fadeIn | opacity 0→1，800ms |

#### 状态变化

| 状态 | 输入框 | 按钮 |
|------|--------|------|

| **已填内容** | 显示内容，可编辑 | 亮起，点击后跳转洗牌页 |
| **点击 Chip** | Chip 文字替换输入框内容 | 亮起 |
| **键盘弹起** | 页面整体上移，输入框保持可见 | — |

## 五、交互动效汇总

| 页面 | 动效 | 类型 | 建议实现方式 |
|------|------|------|------------|
| 首页 | 星空粒子飘动 | 循环背景 | CSS animation 多颗粒子 |
| 首页 | 牌面浮动+微旋转 | 循环 | CSS transform animation |
| 首页 | 主按钮呼吸光效 | 循环 | box-shadow animation |
| 首页→输入 | 页面过渡 | 一次性 | fade 400ms |
| 输入页 | 输入框聚焦边框 glow | 交互反馈 | transition + focus 伪类 |
| 输入页 | Chip 点击微缩放 | 交互反馈 | scale 0.95→1.0，150ms |
| 洗牌 | 牌背交替穿插 | 自动播放 | CSS animation 序列 |
| 选牌 | 牌面悬停微放大 | 交互反馈 | hover scale 1.05 |
| 选牌 | 选中上浮+glow | 交互反馈 | translateY + box-shadow |
| 翻牌 | 3D rotateY 翻转 | 自动序列 | CSS 3D transform，逐张触发 |
| 解读 | 段落逐段淡入 | 自动序列 | fadeIn + translateY，逐段延迟 |
| 解读 | Loading 文案轮换 | 加载态 | 文字切换 animation |
| 页面间 | 所有页面 fade 过渡 | 导航 | 400ms |
