## 一、为什么要做竞品分析？

在 PM 的工作流里，竞品分析不是"看看别人做了什么"，而是回答三个问题：

| 问题 | 你要得到什么 |
|------|------------|
| **别人解决了什么？** | 理解这个赛道的"标准答案"是什么 |
| **别人没解决什么？** | 找到我们的差异化空间 |
| **别人怎么赚钱？** | 判断商业模式可行性，决定我们以后怎么变现 |

> 💡 **小白提示**：竞品分析最忌讳的是"列功能表"。好的分析要回答——**这个功能为什么做？用户买账吗？我能抄吗？**

---

## 二、分析框架说明

这次我们用五个维度拆解每个竞品：

| 维度 | 对应问题 | 你会学到 |
|------|---------|---------|
| **战略层** | 它想服务谁？解决什么问题？怎么赚钱？ | 产品定位、商业模式 |
| **范围层** | 它做了什么功能？没做什么？ | MVP 边界判断 |
| **结构层** | 用户怎么走完一个流程？ | 用户路径设计 |
| **框架层** | 页面怎么布局？按钮怎么放？ | 交互设计参考 |
| **表现层** | 看起来什么感觉？配色、动效、字体 | 视觉风格参考 |
| **AI 能力** | 如果用了 AI，怎么用的？Prompt 质量？ | AI 产品设计参考 |

### 竞品 1：测测

#### 战略层

| 维度 | 分析 |
|------|------|
| **产品定位** | 泛心理服务平台——"测测，更懂你" |
| **目标用户** | 18-35岁年轻人（82%），女性为主 |
| **核心价值主张** | 免费测试引流 + 真人达人付费咨询 |
| **商业模式** | Freemium：免费心理测试/MBTI/星座 → 付费达人问答（10-40元/分钟）+ 订阅会员 |
| **关键数据** | 注册用户近6000万，年收入过亿，App Store年收入约$500万+，获腾讯投资 |
| **市场规模验证** | ✅ 已验证：中国年轻人为"了解自己"付费意愿强 |

#### 范围层（功能列表）

| 有 | 没有 |
|---|------|
| 心理测试（MBTI/性格/职场） | 纯 AI 塔罗深度解读 |
| 星座运势 + 星盘 | 用户自定义问题输入 |
| 真人达人 1v1 咨询 | 牌阵选择自由度 |
| 社区 / 动态 feed | 解读记录与追踪 |

> 🔍 **关键发现**：测测的"塔罗"功能其实很弱——主要是真人达人手动解读，AI 只用于基础匹配。**AI 个性化塔罗解读是它的空白地带。**

#### 结构层（用户路径）

```
打开App → 首页推荐测试/达人 → 做免费测试 → 看结果
                                    ↓
                              想要更多 → 付费找达人咨询（真人）
```

**测测的核心逻辑是"测试引流转达人付费"，不是"AI 服务"。**

#### 框架层 + 表现层

| 维度 | 评价 |
|------|------|
| **视觉风格** | 紫色系、星空/宇宙主题、神秘感+现代感 |
| **交互感受** | 卡片式布局，滑动顺畅，测试交互有趣（选图/选词） |
| **第一印象** | "挺好看的，像社交App"——沉浸感一般，偏工具化 |

#### AI 能力

| 维度 | 评价 |
|------|------|
| **AI 使用程度** | ⭐⭐（低） |
| **AI 用途** | 基础心理测试匹配、内容推荐算法 |
| **Prompt 质量** | N/A（不以 AI 对话为核心） |

#### 总体评价

| 优点 | 缺点 |
|------|------|
| ✅ 用户量大，需求已验证 | ❌ 依赖真人达人，边际成本高 |
| ✅ 商业模式清晰（免费→付费达人） | ❌ AI 能力弱，不是 AI 原生产品 |
| ✅ 获腾讯投资，资源充足 | ❌ 功能臃肿，什么都有但都不深 |
| ✅ 测试类内容天然有传播性 | ❌ 塔罗功能不突出，淹没在众多功能中 |

#### 🎯 灵境可借鉴

| 借鉴点 | 如何应用 |
|--------|---------|
| 紫色/星空视觉风格 | 灵境可以用深紫+金色+星空氛围，建立"心灵之境"感 |
| 免费→付费达人路径 | 灵境可以：免费AI解读 → 未来接入真人达人（V3+） |
| MBTI/测试的传播性 | 解读结果做成"可分享卡片"，自带传播属性 |
| 用户量大但AI薄弱 | **我们的机会：把AI解读做到极致，测测做不到** |

### 竞品 2：Tarotap

#### 战略层

| 维度 | 分析 |
|------|------|
| **产品定位** | 交互式 AI 塔罗——"你的AI塔罗大师" |
| **目标用户** | 对塔罗好奇的全球用户（含中文用户） |
| **核心价值主张** | 免费、多牌阵、可定制 AI 解读风格、支持中文 |
| **商业模式** | 完全免费（目前），靠广告或未来增值服务 |
| **关键数据** | RankmyAI Top 3，中文支持最好的海外AI塔罗 |

#### 范围层（功能列表）

| 有 | 没有 |
|---|------|
| 多牌阵选择（单牌/三牌/凯尔特十字） | 用户账号系统 |
| AI 解读 + 追问对话 | 记录保存（无账号） |
| 可定制 AI 大师风格 | 分享功能 |
| 中文/英文等多语言 | 付费体系 |
| 正逆位显示 | 仪式感动画 |

#### 结构层（用户路径）

```
打开网页 → 选择牌阵 → 输入问题 → 点击抽牌 → AI生成解读 → 可追问/重新抽
```

**路径极简，但从"选牌阵"开始——对小白用户有认知门槛。**

#### 框架层 + 表现层

| 维度 | 评价 |
|------|------|
| **视觉风格** | 简洁现代，深色背景+牌面图，偏工具感 |
| **牌面交互** | 点击翻开，简单直接——但缺少"仪式感" |
| **第一印象** | "能用，但没什么感觉"——功能导向，情绪价值弱 |

#### AI 能力

| 维度 | 评价 |
|------|------|
| **AI 使用程度** | ⭐⭐⭐⭐（高） |
| **AI 用途** | 生成塔罗解读文案、支持追问对话 |
| **Prompt 质量推测** | 基础牌义 + 用户问题拼凑，解读有一定个性化但偏通用 |
| **解读深度** | 中等——能回答用户问题但不够"惊艳" |

#### 总体评价

| 优点 | 缺点 |
|------|------|
| ✅ 中文支持好，低门槛 | ❌ 无仪式感，体验偏"工具" |
| ✅ 多牌阵可选，功能完整 | ❌ 解读模板化痕迹明显 |
| ✅ 完全免费 | ❌ 无账号→无留存→无数据积累 |
| ✅ 可追问，对话感好 | ❌ 视觉设计普通，不"美" |

#### 🎯 灵境可借鉴

| 借鉴点 | 如何应用 |
|--------|---------|
| 多牌阵选择 + 追问对话 | 灵境 MVP 做"三牌阵 + 追问"，保持简洁但完整 |
| 中文支持做得好 | 我们要做到"中文文化理解"，而不仅是"中文翻译" |
| 缺少仪式感 | **我们的差异化：加强抽牌动画、音效、氛围——让用户"感到"在抽牌** |
| 无账号无留存 | **灵境需要：至少本地存储记录，让用户能回顾** |

### 竞品 3：Labyrinthos

#### 战略层

| 维度 | 分析 |
|------|------|
| **产品定位** | 塔罗学习平台——"用古老智慧认识自己" |
| **目标用户** | 想学塔罗的新手 + 自我探索者 |
| **核心价值主张** | 精美设计 + 系统化塔罗课程 + 每日抽牌练习 |
| **商业模式** | Freemium：免费基础功能 + 付费会员（$4.99/月）解锁高级课程 |
| **关键数据** | iOS 评分 4.8+，设计类奖项常客，下载量百万级 |

#### 范围层（功能列表）

| 有 | 没有 |
|---|------|
| 系统化塔罗课程（含测验） | AI 个性化解读 |
| 每日抽牌 + 日记 | 用户自定义问题输入 |
| 精美牌面 + 翻牌动画 | 追问/对话 |
| 学习进度追踪 | 中文支持 |
| 数据统计（抽牌历史） | 社交/分享 |

#### 结构层（用户路径）

```
打开App → 今日抽牌 → 翻牌动画 → 显示牌义 → 写日记（可选）
              ↓
         想学更多 → 进入课程 → 按章节学习 → 做测验
```

#### 框架层 + 表现层

| 维度 | 评价 |
|------|------|
| **视觉风格** | ⭐⭐⭐⭐⭐ 行业顶级——柔和色调、精美插画、细腻动效 |
| **翻牌交互** | 手指滑动翻牌，配合动画，**仪式感极强** |
| **第一印象** | "太美了"——设计本身就是留存理由 |

#### AI 能力

| 维度 | 评价 |
|------|------|
| **AI 使用程度** | ⭐（极低） |
| **AI 用途** | 几乎无 AI——解读依赖固定牌义库 |
| **解读个性化** | ❌ 所有用户看到同样的牌义解释 |

#### 总体评价

| 优点 | 缺点 |
|------|------|
| ✅ 设计美学行业标杆 | ❌ 解读死板——同一张牌永远是同样的解释 |
| ✅ 翻牌交互仪式感极强 | ❌ 无个性化——不懂用户具体在问什么 |
| ✅ 教育属性建立深度使用习惯 | ❌ 无中文 |
| ✅ 高评分验证了"仪式感"的市场需求 | ❌ 变现偏慢（依赖课程订阅） |

#### 🎯 灵境可借鉴

| 借鉴点 | 如何应用 |
|--------|---------|
| 🎨 **翻牌交互设计** | **这是最重要的借鉴！** 灵境的抽牌环节必须设计翻牌动画、音效、过渡动效 |
| 📔 每日抽牌+日记 | MVP 做"解读记录列表"，后续加"日记/反思"功能 |
| 📊 学习追踪 | MVP 做"历史记录"，V2 做"你的心灵轨迹"数据可视化 |
| 解读太死板 | **我们的差异化：AI 让同一张牌对100个人有100种解读** |

### 竞品 4：Co-Star

#### 战略层

| 维度 | 分析 |
|------|------|
| **产品定位** | AI 驱动社交化星座——"用 NASA 数据+AI，给你量身星座解读" |
| **目标用户** | Z 世代（18-25），欧美为主 |
| **核心价值主张** | 精准天文数据 + AI 个性化解读 + 朋友星座兼容性 |
| **商业模式** | Freemium：免费日常解读 + $2.99/月解锁高级功能 |
| **关键数据** | 全球下载量千万级，多次登顶 App Store 生活方式榜，融资超 $20M |

#### 范围层（功能列表）

| 有 | 没有 |
|---|------|
| 基于 NASA 数据的出生星盘 | 塔罗 |
| AI 生成每日运势（个性化） | 中文支持 |
| 朋友星座兼容性分析 | 达人/社区 |
| "今天运势"推送（毒舌风格） | 用户自定义问题 |
| 社交裂变（添加好友→看兼容性） | 传统星座内容 |

#### 结构层（用户路径）

```
输入出生信息 → 生成星盘 → 每日收到一句AI运势推送
                              ↓
                         添加好友 → 看"你们为什么合不来/合得来"
                              ↓
                         截图分享到 Instagram → 新用户看到 → 下载
```

> 🔥 **Co-Star 厉害的不是功能，是社交裂变**——用户主动把解读截图分享到社交媒体，成为免费增长引擎。

#### 框架层 + 表现层

| 维度 | 评价 |
|------|------|
| **视觉风格** | 极简黑白+无衬线字体，反常规的"反设计"——像一张NASA打印报告 |
| **文案风格** | ⭐⭐⭐⭐⭐ 毒舌、直白、不讨好——"你今天很烦人""不要联系前任" |
| **第一印象** | "这 App 好 mean，但我好喜欢"——差异化文案制造情感连接 |

#### AI 能力

| 维度 | 评价 |
|------|------|
| **AI 使用程度** | ⭐⭐⭐（中等） |
| **AI 用途** | 根据星盘+用户历史生成个性化运势文案 |
| **Prompt 质量推测** | 风格提示词很精准——"毒舌但关心你的朋友"这个 tone 贯穿始终 |

#### 总体评价

| 优点 | 缺点 |
|------|------|
| ✅ 社交裂变教科书——分享即获客 | ❌ 只做星座，品类窄 |
| ✅ 毒舌文案风格独特，品牌感强 | ❌ 无中文，中国市场空白 |
| ✅ AI 不是"通用解读"而是"个性化 tone" | ❌ 每天一句话，功能太轻 |
| ✅ Z 世代文化符号 | ❌ 深度解读需付费 |

#### 🎯 灵境可借鉴

| 借鉴点 | 如何应用 |
|--------|---------|
| 🔥 **解读结果做成可分享卡片** | MVP 必做！解读页一键生成精美的分享图 |
| 📝 独特的 AI 文案风格 | 灵境的 tone：温柔但不说废话、专业但不冷漠、像"懂塔罗的朋友" |
| 👥 社交裂变机制 | 分享卡片带二维码/链接 → 新用户扫码即可体验 |
| 📅 每日推送 | V2 做"每日一张牌"或"今日塔罗一句话" |

### 竞品 5：中文 AI 塔罗 Web App（泛品类分析）

> 代表产品：TarotAI.art、AI塔罗占卜（多个小程序）、各类魔塔罗 Web 工具

#### 战略层

| 维度 | 分析 |
|------|------|
| **产品定位** | 免费 AI 塔罗解读工具——"输入问题→抽牌→得到解读" |
| **目标用户** | 对塔罗好奇的中文互联网用户 |
| **核心价值主张** | 免费、快速、AI 解读 |
| **商业模式** | 几乎全部免费，无明显商业模式（广告/引流为主） |

#### 范围层（功能列表）

| 都有 | 都没有 |
|------|--------|
| 输入问题 → 选/抽牌 | 个性化解读（都偏模板化） |
| AI 生成解读文案 | 仪式感动画/音效 |
| 基本牌阵（单牌/三牌） | 账号系统/记录保存 |
| 网页即用，无需下载 | 分享功能 |
| | 牌面美术设计（多用免费素材） |
| | 追问/对话 |

#### 结构层（用户路径）

```
打开网页 → 输入问题 → 点击"抽牌" → 随机显示3张牌 → AI生成一段解读 → 结束
```

**用户路径极短，用完即走——没有留存机制，没有品牌认知。**

#### 总体评价

| 共性问题 | 我们的机会 |
|---------|----------|
| ❌ 解读模板化——不同问题得到相似回答 | ✅ 我们设计深度 Prompt，让每份解读贴合用户的具体问题 |
| ❌ 无仪式感——"抽牌"就是点个按钮 | ✅ 我们设计翻牌动画+音效+氛围渲染 |
| ❌ 无留存——用完就走 | ✅ 我们做本地存储+历史记录+分享回流 |
| ❌ 视觉廉价——免费模板感强 | ✅ 我们做紫色星空+精美牌面+统一设计语言 |
| ❌ 无追问——一段话结束 | ✅ 我们支持追问对话，让用户"聊下去" |
| ❌ 无品牌——用户记不住名字 | ✅ 从Day1就建立"灵境"品牌感 |

| **用户量** | 6000万 | 未知（较小） | 百万级 | 千万级 | 碎片化 | 从0开始 |

## 六、核心洞察与灵境的行动指南

### 洞察 1：目前没有产品同时做到"AI个性化 + 仪式感"

```
测测：有用户、有商业模式，但 AI 弱
Labyrinthos：仪式感极致，但解读死板、无 AI
Tarotap：AI 不错，但体验像工具、没感觉
Co-Star：文案很个性化，但只做星座、不抽牌
中文泛品：什么都有，什么都不精
```

**→ 灵境的定位 = Labyrinthos 的仪式感 × Tarotap 的 AI 能力 × Co-Star 的社交裂变 × 中文文化理解**

### 洞察 2：留存是所有竞品的共同短板

除了测测（靠社区）和 Labyrinthos（靠教育），其他竞品都是"用完即走"。

**→ 灵境需要从 Day1 就设计留存机制：**
- 解读记录列表（"我的心灵轨迹"）
- 分享卡片带回流二维码
- 每天的解读可对比回顾

### 洞察 3：视觉设计本身可以成为获客理由

Labyrinthos 证明：用户会**因为"好看"而下载并留在一个 App**。
Co-Star 证明：**独特的设计风格**本身就是品牌和传播素材。

**→ 灵境的设计需要"美到用户想截图分享"**

### 洞察 4：AI Prompt 的"口吻"比"准确度"更重要

Co-Star 的毒舌风格让用户觉得"这个 App 懂我"，哪怕它只是 AI 生成的。

**→ 灵境需要定义清晰的 AI 人格：温暖、专业、不说废话、像"懂塔罗的朋友"**

## 七、竞品分析结论

### 灵境的差异化定位总结

> **灵境 = 有仪式感的抽牌体验 + AI 深度个性化解读 + 持续记录追踪 + 可分享的优美结果页**

### 机会确认

| 判断 | 依据 |
|------|------|
| ✅ 赛道有需求 | 测测6000万用户、Tarotap Top3排名、抖音#塔罗100亿+播放 |

| ✅ 可参考的模板清晰 | Labyrinthos（仪式感）+ Tarotap（AI）+ Co-Star（裂变） |
| ✅ 变现路径已验证 | 测测（达人付费）、Labyrinthos（订阅）、Co-Star（Freemium） |
| ⚠️ 需要突破的点 | Prompt质量、视觉设计、留存机制——这三件事决定灵境能否"成立" |
