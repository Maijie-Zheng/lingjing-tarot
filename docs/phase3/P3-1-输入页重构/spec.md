## 一、题库 JSON 规格

### 1.1 结构

```json
{
  "categories": {
    "love":   { "label": "感情", "icon": "Heart" },
    "career": { "label": "事业", "icon": "Briefcase" },
    "self":   { "label": "自我", "icon": "Sparkles" },
    "daily":  { "label": "日常", "icon": "Moon" }
  },
  "questions": [ ... ]
}
```

### 1.2 题目字段

| 字段 | 必填 | 说明 |
|------|------|------|
| id | 是 | 唯一标识，如 `love-01` |
| cat | 是 | 分类 key：`love` / `career` / `self` / `daily` |
| state | 是 | 情绪标签（暧昧/消耗/抉择/趋势等），暂不渲染但预留扩展 |
| text | 是 | 问题文案 |
| when | 否 | 时段/星期规则 |

### 1.3 时段规则

- `when.hours: [a, b)` — 当前小时 ∈ `[a, b)` 时命中
- `when.weekday: [0, 6]` — `Date.getDay()`（0=周日）匹配时命中
- 无 `when` 字段 → 任何时间可出（通用兜底）

## 二、出题逻辑

### 2.1 配额

每批固定 5 条：**感情 2 + 事业 1 + 自我 1 + 日常(机动) 1**

### 2.2 洗牌队列

- 每个分类维护一个洗牌队列
- 每次取一条从队列前端取出（移除）
- 队列耗尽后重新洗牌（shuffle）
- 机动位取第一条命中当前时段的，若无则取第一条无线段限制的
- 池子耗尽前不出重复

### 2.3 Hook 接口

```js
const { batch, next } = useQuestionBatch()
// batch: Array<Question>（当前 5 条）
// next: () => void（换一批）
```

## 三、选中与填入交互

| 操作 | 行为 |
|------|------|
| 点击预设卡片 | `setText(q.text)` + `setSelectedId(q.id)` |
| 再次点击同一张 | 取消选中 + 清空输入框 |
| 手动编辑文字 | `selectedId` 保留（语义：此问题源于该预设） |
| 清空输入框（trim 后为空） | `selectedId` 置 null |
| 换一批后选中卡片不在新批次 | 选中态消失，输入框文字保留 |
| 按钮禁用态 | `text.trim()` 为空时 40% 透明、无呼吸动画、cursor-not-allowed |

## 四、视觉规格

### 4.1 页面结构

```
┌────────────────────────────────┐
│ ← 返回                        │
│                                │
│   灵境已启，说说你的心事吧     │  ← 宋体 20px，字距 3px
│                                │
│ ┌────────────────────────────┐ │
│ │ 写下你的心事…              │ │  ← 磨砂玻璃 textarea
│ │                            │ │     border-gold/[.22]
│ │                            │ │     聚焦时 border-gold/60
│ └────────────────────────────┘ │
│ 🔒 你的心事，仅存于你的掌心    │  ← Lock 图标
│                                │
│ 试试这些问题         🔄 换一批 │  ← RefreshCw 图标
│                                │
│ ┌────────────────────────────┐ │
│ │ 💛 感情 ┆ TA对我是什么感觉  │ │  ← 选中态：金色边框+光晕+✓
│ └────────────────────────────┘ │
│ ┌────────────────────────────┐ │
│ │ 💛 感情 ┆ 我们有可能吗      │ │  ← 默认态：细金边框
│ └────────────────────────────┘ │
│ ...                            │
│                                │
│ [ ✨ 开启灵境 ]               │  ← GoldButton，无内容时 40% 透明
└────────────────────────────────┘
```

### 4.2 预设卡片

- 分类图标（Heart/Briefcase/Sparkles/Moon）+ 分类标签 + 竖分隔线 + 问题文字
- 默认态：`border-gold/[.16]` / `bg-white/[0.04]`
- hover 态：`border-gold/40`
- 选中态：`border-gold/[.65]` + `bg-gold/10` + 金色外发光 + 右侧 Check 图标 + 文字提亮

### 4.3 进场动画

- 返回按钮 → 标题 → 输入框 → 列表逐条，fade-up 错落 0.08s

### 4.4 错误处理

- Go 按钮不存在 → 显示「该阶段开发中…」（兜底）
- JSON 加载失败 → 空数组兜底，不阻塞页面渲染
