# P0-3 · 抽牌体验重做 — 规格说明

> 状态：📝 待确认 | 日期：2026/06/09 | 属于：第二阶段 → 仪式感提升

---

## 一、现状

| 维度 | 当前状态 |
|------|---------|
| 选牌方式 | 3×3 网格，9 张牌背平铺 |
| 交互 | 点击选中→显示序号角标→点确认→统一翻牌 |
| 翻牌时机 | 3 张全选完后，在 reveal 阶段逐张翻 |
| 牌面尺寸 | 全部 sm（64×96） |
| 用户感受 | "牌太小、太密，没有选牌的感觉，像在点按钮" |

### 当前代码结构（ShufflePage.jsx）

```
3 阶段状态机：
  shuffle (2.5s) → select (3×3 grid) → reveal (逐张翻) → 跳转解读页

选牌逻辑：
  - 9 张牌随机抽取 → 3×3 CSS Grid
  - 点击选中/取消 → 序号角标
  - 满 3 张 → 点「确认」→ 进入 reveal
  - reveal：循环 setTimeout 逐张翻牌（3D rotateY）
```

### 问题分析

1. **牌太小**：sm 尺寸在 375px 屏幕上只有 64×96，看不清
2. **没有"抽牌感"**：9 张平铺在一起，用户只是点按钮，不像在"抽"
3. **选完才翻**：用户想知道自己抽到了什么，但必须等 3 张全选完
4. **只有 9 张**：22 张大阿尔卡纳只用 9 张，选择范围太小

---

## 二、目标

把抽牌体验从"点三个按钮"升级为"亲手从牌堆中抽出命运"。

核心改动：
1. **滚动轮播**：22 张牌水平滚动，中心牌放大聚焦
2. **选即翻**：点击中心牌 → 立刻翻转 → 加入底部已选区
3. **直觉选牌**：用户可以慢慢滑动，凭直觉找到"有感觉"的牌
4. **沉浸仪式**：滑动时牌背流动，中心牌像"在发光召唤你"

---

## 三、技术方案

### 3.1 交互流程

```
洗牌动画 (1.5s)
    ↓
滚动选牌 ← 核心交互
    ├── 22 张牌背水平排列
    ├── 可左右滑动浏览
    ├── 中心位置牌自动放大 (lg: 140×210)
    ├── 两侧牌逐渐缩小 (md→sm)
    ├── 点击中心牌 → 3D 翻转 → 显示牌面
    ├── 翻开的牌从轮播中"飞入"底部已选区
    └── 已翻的牌在轮播中变灰/不可再选
    ↓
选满 3 张 → 1s 停顿 → 自动进入解读页
```

### 3.2 轮播设计

```
         ← 滑动方向 →

    [sm]  [md]  [LG]  [md]  [sm]
    牌背   牌背  牌背   牌背   牌背
           ↖    ↑    ↗
         两侧缩小  中心放大聚焦（140×210）

点击中心牌 → 3D 翻转 → 牌面露出 → 飞入底部
```

### 3.3 底部已选区

```
选定第 1 张后：
┌─────────────────────────────────┐
│  [已翻牌1]  [空位2]  [空位3]    │
│   过去      现在      未来       │
└─────────────────────────────────┘

选定第 3 张后 → 1s 停顿 → 自动进入解读页
```

### 3.4 代码改动范围

| 文件 | 改动类型 | 说明 |
|------|---------|------|
| `src/components/CardCarousel.jsx` | 🆕 新建 | 水平滚动轮播组件 |
| `src/pages/ShufflePage.jsx` | 🔧 重写 | 简化状态机，集成轮播 |

### 3.5 CardCarousel 组件规格

```jsx
// Props
{
  cards: Array,           // 22 张牌数据
  selectedIds: Set,       // 已选中牌的 id 集合
  onSelect: (card) => void,  // 选中回调
  maxSelect: 3,           // 最多选几张
}

// 行为
- 使用 CSS scroll-snap 实现吸附效果
- 监听 scroll 事件，判断当前中心牌
- 中心牌放大（scale 1.0），两侧缩小（scale 0.7 / 0.5）
- 点击/触摸中心牌触发 onSelect
- 已选中的牌在轮播中显示为牌面（已翻）并降低透明度
- 左右两侧有渐变遮罩，暗示"还有更多"
```

### 3.6 CSS Scroll Snap 实现

```css
/* 轮播容器 */
.carousel-container {
  display: flex;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
  -webkit-overflow-scrolling: touch;
  scrollbar-width: none;  /* 隐藏滚动条 */
  /* 左右 padding 让首尾牌也能滑到中心 */
  padding: 0 calc(50% - 70px);  /* 中心牌宽度的一半 */
}

/* 每张牌的槽位 */
.carousel-item {
  scroll-snap-align: center;
  flex-shrink: 0;
}
```

### 3.7 ShufflePage 状态机简化

```
改动前：shuffle → select → reveal（3 阶段）
改动后：shuffle → select（2 阶段，翻牌融入 select 中）

stage === 'shuffle':
  洗牌动画（缩短至 1.5s）→ 自动进入 select

stage === 'select':
  CardCarousel + 底部已选区
  选满 3 张 → 1s 后 navigate('/reading')
```
