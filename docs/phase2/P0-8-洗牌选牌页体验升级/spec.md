## 一、操作引导优化

### 1.1 文案升级

| 位置 | 旧 | 新 |
|------|-----|-----|
| 选牌引导 | "滑动浏览，凭直觉选出 3 张牌" | "指尖轻滑，凭心指引，选出属于你的三张牌" |
| 进度提示 | "第 1 张：代表「过去」" | 去掉 emoji，改为动态切换 |
| 卡槽标签 | "过去/现在/未来" | "🌙 过去 · 溯源" / "✨ 现在 · 当下" / "🌟 未来 · 趋势" |
| 选满提示 | "命运之牌已揭示，即将进入解读..." | "命运之牌已揭示，灵境正在解读..." |

### 1.2 轻量引导动画

进入选牌阶段后：
- 卡牌组做一次"呼吸 + 滑动示意"：中心牌轻微放大再缩小 + 整组牌向左微移再回弹
- 只播放一次（2s 后停止），避免持续干扰
- 让用户一眼就知道"可以滑动"

### 1.3 卡槽形式

当前：底部 3 个虚线方块 + 文字标签

改为：
- 半透明磨砂卡槽（和输入框风格统一）
- 空卡槽：圆角矩形 + 虚线边框 + 位置 emoji + 诗意标签
- 满卡槽：实心边框微光 + 牌面缩略图
- 选牌后卡牌"飞入"卡槽：motion.div 从卡片位置飞到卡槽位置（用 `layoutId` 或手动计算）

## 二、状态反馈强化

### 2.1 选中卡牌反馈

当前：金色边框 `box-shadow`

改为：
- **上浮**：选中瞬间卡牌 `y: -8`，spring 回弹
- **光晕扩散**：选中后 `box-shadow` 从中心向外扩散（0→24px→40px→稳定 20px）
- **星芒闪烁**：牌背在翻转前（0.6s 翻转期间），牌背中心出现星芒闪烁
- 翻转后牌面显示 + 半透明叠加

### 2.2 进度提示动态更新

顶部进度区（选择阶段始终可见）：
```
已选 0 张："指尖轻滑，凭心指引，选出属于你的三张牌"
已选 1 张："🌙 第一张已感应，再选「现在 · 当下」"
已选 2 张："✨ 第二张已感应，最后选「未来 · 趋势」"
已选 3 张："🌟 三张已齐聚，命运之牌已揭示..."
```

用 AnimatePresence 做文案切换时的淡入淡出。

## 三、视觉氛围

### 3.1 卡牌景深效果

当前：CardCarousel 已有 scale 衰减（1 → 0.78 → 0.6），但不够明显

增强：
- 中心牌：`scale: 1`，`opacity: 1`，`brightness(1)`
- 左右各 1 张：`scale: 0.8`，`opacity: 0.7`，`brightness(0.7)`
- 左右各 2 张：`scale: 0.6`，`opacity: 0.4`，`brightness(0.5)`
- 更远的牌：`scale: 0.45`，`opacity: 0.2`

用 CSS `filter: brightness()` 配合 Framer Motion animate 实现。

### 3.2 中心光晕

卡牌组中心区域（背景层）加入一个淡淡的圆形光晕（径向渐变）：
- 颜色：`rgba(139, 92, 246, 0.06)` — 辅助紫色，呼应品牌
- 尺寸：约 280px，覆盖中心 2-3 张牌的范围
- 呼吸动画：3s 循环，opacity 0.5→1→0.5
- 像"灵境通道"一样引导视线聚焦

### 3.3 牌背升级

当前牌背：深蓝底 + 金色边框 + 中心 ✦ + 四角 ✦

改为更细腻的设计（保持 CSS 绘制，零图片）：
- 底色：`linear-gradient(135deg, #0d1b3e, #162447)` 保持
- 外层边框：`1px solid rgba(201,169,110,0.3)` 保持
- **新增星盘线**：两条极细的对角线交叉（X 形），`rgba(201,169,110,0.15)`
- **新增环形轨道**：2 个同心圆环（`border-radius: 50%`），`rgba(201,169,110,0.1)`
- **中心星**：`✦` 保持，颜色加深到 `rgba(201,169,110,0.5)`
- **四角符文**：四个角放极小的神秘符号（用 CSS 绘制小圆点组成的几何图形），`rgba(201,169,110,0.25)`

牌背整体保持神秘低调——"在微光下才隐约可见"。

### 3.4 选中态边框

当前：`box-shadow: 0 0 20px rgba(201,169,110,0.6), 0 0 40px rgba(201,169,110,0.2)`

改为渐变描边 + 外发光：
- 边框色：`rgba(201,169,110,0.55)` — 柔金色
- 外发光：三层叠加
  ```
  box-shadow:
    0 0 12px rgba(201,169,110,0.3),     // 紧贴发光
    0 0 30px rgba(201,169,110,0.15),    // 中距离
    0 0 50px rgba(201,169,110,0.06)     // 远距离光晕
  ```
- 和 AskPage 聚焦光效的三层 shadow 风格统一

## 四、交互仪式感

### 4.1 静心引导（新增阶段）

在当前 "shuffle" 阶段之前，新增 "meditate" 阶段：

**流程**：meditate（3s）→ shuffle（1.5s）→ select

**meditate 阶段内容**：
- 屏幕微微变暗（背景加一层半透明遮罩）
- 中央显示文字："请闭上眼睛，深呼吸，在心中默念你的问题…"
- 文字做呼吸动画（opacity 3s 循环，0.4→0.8→0.4）
- 3s 后自动进入 shuffle 阶段
- 用户可以点击跳过（"跳过 →" 文字按钮在底部）

**动画衔接**：meditate 文字淡出 → shuffle "正在为你洗牌..." 淡入

### 4.2 洗牌阶段

保持当前 1.5s 洗牌动画 + 进度条，但：
- 洗牌文字改为："✨ 灵境正在为你洗牌..."
- 进度条颜色改为品牌金色渐变（左暗右亮）

### 4.3 选牌阶段 —— 选中动画流程

每选一张牌的完整动画序列：

1. **点击中心牌** → 牌背上浮 8px + 星芒闪烁（0.3s）
2. **翻转动画**（0.6s，保持现有）→ 牌面显示
3. **星点汇聚**（0.4s）→ 牌面周围出现 6-8 颗小光点，汇聚到牌的中心
4. **飞入卡槽**（0.4s）→ 缩小版的牌从大牌位置飞到对应卡槽位置（AnimatePresence + layoutId）
5. **卡槽亮起**（0.3s）→ 对应卡槽的虚线边框变为实线微光，标签高亮

动画总时长约 1.7s，视觉上连贯流畅。

### 4.4 滑动惯性回弹

当前：原生 `scrollTo({ behavior: 'smooth' })`

改为：
- 在 scroll 事件中不干预
- 利用 CSS `scroll-snap-type: x mandatory` + `scroll-snap-stop: always` 加强吸附
- 添加 `overscroll-behavior: contain` 防止页面整体滑动

（注：真正的"惯性回弹"在移动端 Web 上受限于浏览器能力，通过 CSS scroll-snap 模拟最佳体验即可，不引入手势库。）

### 4.5 选满后过渡

三张牌选满后：
- 当前：1s 停顿 → 直接 navigate
- 改为：
  1. 三张卡槽同时微微发光（0.5s）
  2. 中央出现"星光汇聚"光效（0.5s）
  3. 光效扩散全屏变白（0.3s）→ 自然过渡到解读页
  4. navigate 时机调整到光效扩散完成时（约 1.3s 后）

### 4.6 "换问题"按钮

当前：纯文字链接 `← 换问题`

改为：
- 样式和 AskPage 的返回按钮保持一致
- 微光文字 + hover 时亮起
- 点击时轻微星芒动画（和 AskPage chip 的 whileTap 风格一致）

## 五、品牌一致性

### 5.1 "你在问"区域

当前：mystic-card（半透明 + 模糊）

改为完全对齐 AskPage 输入框风格：
- 背景：`rgba(255,255,255,0.04)` + `backdrop-filter: blur(12px)`
- 边框：`1px solid rgba(255,255,255,0.08)`（全边框）
- 圆角：`rounded-card`（12px）
- 内阴影：`inset 0 1px 0 rgba(255,255,255,0.03)`
- 问题文字：`text-white/80`，字号 `text-sm`

### 5.2 设计语言对齐表

| 模块 | AskPage（上一界面） | ShufflePage（本次目标） |
|------|---------------------|------------------------|
| 问题展示卡 | 磨砂玻璃 + 全边框 + 微光 | 同款磨砂玻璃卡片 |
| 选中/聚焦态 | 三层金色光晕 + 边框过渡 | 三层金色光晕 + 边框过渡 |
| 按钮微光 | hover 光晕扩散 | hover 光晕扩散 |
| 动效 | 呼吸、微光扩散 | 呼吸引导、光晕扩散、星点汇聚 |
| 文案 | 诗意、温柔 | 诗意、仪式感 |

### 5.3 不做

- ❌ 不引入音效（音频文件太大，移动端加载慢）
- ❌ 不引入新的 npm 依赖（手势库等）
- ❌ 不改牌面数据（tarotCards.js）
- ❌ 不改路由逻辑（跳转行为不变）
- ❌ 不改选牌数量（保持 3 张）
- ❌ 不改 StarBackground 全局组件
- ❌ 不引入新的图片资源（牌背纯 CSS 绘制）

## 六、阶段流程总览

```
用户进入 /shuffle
  │
  ├─→ 阶段 0：静心引导（新增，3s）
  │    - 暗化遮罩 + 呼吸文字
  │    - 可跳过
  │    ↓
  ├─→ 阶段 1：洗牌动画（保持，1.5s）
  │    - 5 张牌背交替穿插
  │    - 进度条
  │    ↓
  └─→ 阶段 2：选牌（增强）
       - 呼吸引导动画（首次，2s）
       - 景深卡牌轮播
       - 点选 → 星芒 → 翻转 → 汇聚 → 飞入卡槽
       - 进度文案动态更新
       ↓
     选满 3 张
       ↓
     星光汇聚 → 白屏过渡 → /reading
```
