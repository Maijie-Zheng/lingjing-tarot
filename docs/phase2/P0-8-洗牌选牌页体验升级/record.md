## 改动明细

### 一、Bug 修复：中心牌检测跳偏

**问题**：`updateCenter` 用 `Math.round()` 计算中心牌索引，平滑滚动过程中遇到中间位置会四舍五入跳偏。`scrollToIndex` 的目标值计算也有偏差。

**修复**：
- `updateCenter` → `findClosestCard()`：遍历所有牌，找离视口中心最近的牌
- `scrollToIndex` → `target = index * SLOT_W`（修正了多余的 padding 减法）
- 新增 `isProgrammaticScroll` 标志：程序化滚动期间不更新 centerIndex，结束后直接设为目标值

### 四、交互仪式感

**新增静心引导阶段**（meditate，3s）：
- 半透明暗化遮罩覆盖全屏
- 呼吸文字："请闭上眼睛，深呼吸\n在心中默念你的问题…"
- opacity 0.35→0.8→0.35 循环
- "跳过 →" 按钮，点击立即进入洗牌

**选中动画序列**：
1. 星芒闪烁（350ms）：牌背出现径向金色光晕 + 外发光
2. 翻转（600ms）：3D rotateY 翻转
3. 卡槽星点汇聚（450ms）：8 颗金色光点从四周飞向卡槽中心
4. 卡槽 spring 弹入：牌面缩略图 spring 动画填入卡槽

**滑动体验**：
- `scrollSnapStop: 'always'` 加强吸附
- `overscrollBehavior: 'contain'` 防止页面整体滑动
- 平滑滚动期间锁定 centerIndex 更新

**选满后星光汇聚 + 白屏过渡**（1.3s）：
- 三张选满后 0.8s 触发
- 中心光点爆发 → 全屏白色径向渐变扩散
- 0.6s 后 navigate 到解读页

## 回顾

### 做了什么
把洗牌选牌页从"基础轮播+选牌"升级为完整的仪式感抽牌体验。新增静心引导阶段，牌背星盘化重绘，卡槽磨砂玻璃化，选中动画序列（星芒→翻转→汇聚→飞入），选满星光白屏过渡。

### 为什么这么做
- 洗牌选牌是塔罗体验的核心仪式环节——用户在这个页面的沉浸感直接决定了对 AI 解读的期待值
- 牌背星盘化让"滑动选牌"变得好看，用户更愿意慢慢滑动浏览
- 静心引导把"选牌"从操作变成仪式，降低用户的急躁感
- 三层光晕和磨砂卡槽和 AskPage 保持设计语言一致

### 学到什么
- `Math.round()` 做滚动中心检测不可靠——"找最近元素"的遍历法更稳定
- 程序化滚动期间需要锁住检测逻辑，否则中间帧会误判
- Framer Motion 的 `AnimatePresence` + 动态 key 可以做流畅的文案切换
- 牌背纯 CSS 绘制可以做到很细腻，不需要引入图片资源
