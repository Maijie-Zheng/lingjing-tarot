## 二、内联展开——查看完整解读

### 2.1 交互流程

```
点击卡片 → 卡片下方展开解读详情（Accordion 式）
         → 箭头旋转 180°
         → 显示：三张牌大图 + AI 解读全文
再点击 → 收起
```

### 2.2 展开区布局

```
┌─────────────────────────────────────┐
│ （卡片头部，同 1.2，箭头朝上）        │
├─────────────────────────────────────┤
│                                     │
│  ┌──┐  ┌──┐  ┌──┐                  │
│  │牌│  │牌│  │牌│   ← md 尺寸       │
│  │  │  │  │  │  │   带金色光晕      │
│  └──┘  └──┘  └──┘                  │
│  过去   现在   未来                   │
│                                     │
│  ── ✨ 灵境解读 ──                   │
│                                     │
│  （AI 解读全文，                    │
│   用 ReadingText 组件渲染，          │
│   speed=0 即一次性全部显示）          │
│                                     │
└─────────────────────────────────────┘
```

### 2.3 实现方式

- 用 `useState` 追踪当前展开的记录 ID（`expandedId`），同时只能展开一条
- 展开区复用 `ReadingText` 组件，传入 `rawText={record.reading}` + `cards={record.cards}` + `speed={0}`（一次性全显示，不走分段动画）
- 展开区入场用 `AnimatePresence` + `motion.div` 的 height 动画（`initial={{ height: 0 }}` → `animate={{ height: 'auto' }}`）

### 2.4 边界情况

- 记录中 `reading` 为空 → 显示"解读内容已丢失"
- 记录中 `cards` 缺失 → 不显示牌面，只显示文字
- 超过 50 条记录（localStorage 容量保护）→ 正常

## 三、左滑删除优化

### 3.1 当前问题

使用原始 `onTouchStart` / `onTouchEnd` 检测滑动距离，没有跟手动画，体验生硬。

### 3.2 改进方案

用 Framer Motion 的 `drag` 手势替代原始 touch 事件：

```jsx
<motion.div
  drag="x"
  dragConstraints={{ left: -80, right: 0 }}
  dragElastic={0.1}
  onDragEnd={(_, info) => {
    if (info.offset.x < -40) setSwipedId(id)
    else setSwipedId(null)
  }}
>
```

- 卡片可向左拖拽最多 80px
- 松手时偏移超过 40px → 锁定显示删除按钮
- 未超过 → 弹回原位
- 拖拽时卡片跟手移动（`drag` 自带跟手）

### 3.3 删除按钮

```
┌─────────────────────────────────────┐
│ （卡片，被左推）          │  删除   │
└─────────────────────────────────────┘
                              ↑
                    红色文字，红色半透明底
```
