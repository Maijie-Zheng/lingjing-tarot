## 改动明细

### 一、HistoryPage 重写

#### 1.1 卡片视觉升级

从纯色矩形改为磨砂玻璃卡片：
- `background: rgba(255,255,255,0.03)` + `blur(8px)` + `border: 1px solid rgba(255,255,255,0.06)`
- 展开状态边框变为金色微光（`rgba(201,169,110,0.2)`）+ 额外金色外阴影

#### 1.2 真实牌面缩略图

三张小牌缩略图从 🃏 emoji 改为 `TarotCard size="sm"`（64×96），显示真实韦特塔罗牌面。

#### 1.3 内联展开回看（核心新功能）

- 点击卡片 → 下方展开完整解读
- 展开区复用 `ReadingText` 组件，传入 `speed={0}` 一次性全显示
- 展开箭头 ▼ 旋转 180° 动画
- 同时只能展开一条（accordion 模式）
- 解读内容丢失时显示兜底文案
- 卡片有 `layout` prop，展开/收起时列表自动重排

#### 1.4 左滑删除手势优化

从原始 touch 事件改为 Framer Motion `drag`：
- `drag="x"` + `dragConstraints={{ left: -80, right: 0 }}` + `dragElastic={0.08}`
- 拖拽跟手，松手时偏移超过 40px 锁定删除按钮
- 右滑或点击收起删除按钮

#### 1.5 空状态升级

- 月球 emoji 呼吸动画（opacity 0.5→1→0.5，4s 循环）
- 诗意引导文案："每一次塔罗解读，都是一次与内心的对话。"
- CTA 按钮文案改为"✨ 开始第一次抽牌"

#### 1.6 顶栏品牌化

- 标题从 `📜 我的解读记录` 改为纯文字衬线体 `我的解读记录`
- 右侧显示记录数 `共 N 条`

#### 1.7 清空确认弹窗视觉升级

- 磨砂玻璃背景（深紫半透明 + blur）
- 紫色外发光边框
- 按钮样式统一

### 二、ReadingText 微调

添加 `speed=0` 即时模式：
```js
if (speed === 0) {
  setVisibleCount(sections.length)
  return
}
```
跳过所有 setTimeout 分段动画，所有段落立即渲染。

## 回顾

### 做了什么

把历史记录页从"能看列表"升级为"可回溯的心灵轨迹"。记录卡片用磨砂玻璃容器 + 真实韦特塔罗缩略图替代了 emoji 占位；点击卡片可内联展开完整解读（复用 ReadingText 组件）；左滑删除用 Framer Motion drag 实现跟手拖拽；空状态加入呼吸动画和诗意文案；顶栏去 emoji 化。

### 为什么这么做

- 内联展开是最核心的缺失功能——PRD 写了"点击查看完整解读"但从未实现，用户保存了记录却回看不了
- 真实牌面缩略图比 🃏 emoji 让记录卡片有了"作品感"——用户看到自己选过的牌，愿意反复回来翻看
- Framer Motion drag 比原始 touch 事件更顺滑——跟手拖拽 + spring 回弹的体验更接近原生 iOS
- 空状态的诗意文案让"没有记录"也成为一个有温度的时刻——不是空白页，而是一句邀约
- 历史记录本质是"心灵轨迹"——好的设计让用户愿意回来看、愿意继续抽牌积累记录

### 学到什么

- 历史记录页的价值不只是"存储"——它是用户的情感档案，视觉质感和回看体验直接影响留存
- 复用 ReadingText 组件避免了重复造轮子——`speed=0` 一个参数就解决了"即时显示 vs 分段动画"的差异
- Framer Motion 的 `drag` + `animate` 组合可以替代大部分手势库——声明式 API 足够覆盖常见的 swipe-to-action 场景
- 磨砂玻璃容器贯穿所有页面后，品牌统一感明显增强——用户从首页到历史记录都能感知到"这是灵境"
