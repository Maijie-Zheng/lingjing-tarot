## 目标

## 详细规格

### 1. 灵境之眼（StarEye 组件）

纯 CSS + Framer Motion 实现，不依赖图片。

**结构：**
```
┌──────────────────────────────┐
│                              │
│        ╭─────────╮          │  ← 外层星环（顺时针慢转）
│       ╱           ╲         │
│      │    ╭───╮    │        │  ← 内层星环（逆时针慢转）
│      │   ╱     ╲   │        │
│      │  │   ◆   │  │        │  ← 中心发光菱形（静止 + 呼吸光晕）
│      │   ╲     ╱   │        │
│      │    ╰───╯    │        │
│       ╲           ╱         │
│        ╰─────────╯          │
│                              │
│     ✦ 星点粒子漂浮 ✦          │  ← 6-8 颗小金色粒子，缓慢浮动
│                              │
└──────────────────────────────┘
```

**动画参数：**

| 元素 | 动画 | 时长 |
|------|------|------|
| 外层星环 | `rotate: 360°` 顺时针 | 20s 匀速循环 |
| 内层星环 | `rotate: -360°` 逆时针 | 15s 匀速循环 |
| 中心菱形 | `scale: 0.95→1.05` 呼吸 + 发光光晕 | 3s ease-in-out 循环 |
| 星点粒子 | 上下浮动 ±8px + 透明度呼吸 0.3→1→0.3 | 各粒子不同周期(2-4s)，错开 |

**尺寸约束：**
- 整体视觉区域：约 200×200px（375px 屏宽下）
- 不可溢出，不可触发横向滚动

**配色：**
- 星环线条：`#c9a96e`（品牌金），opacity 0.6-0.8
- 中心菱形：`#c9a96e`，带 `box-shadow` 金色光晕
- 粒子：`#c9a96e` + 少量 `#f0e6d8`（浅金色白），opacity 0.4-0.9

**CSS 绘制方式：**
- 星环用 `border` + `border-radius: 50%` 圆形 + 八芒星镂空效果（可用多个旋转正方形叠加，或用 `clip-path`）
- 中心菱形用旋转 45° 的正方形
- 粒子用绝对定位的小圆点 + Framer Motion 动画
