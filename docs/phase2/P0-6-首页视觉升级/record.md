## StarEye 组件结构

```
┌──────────────────────┐
│ 底层光晕（径向渐变）    │
│ 外层星环（顺时针 20s）  │  8 个金色标记点
│ 内层星环（逆时针 15s）  │  8 个金色标记点（偏移 22.5°）
│ 中心菱形（呼吸 3s）     │  金色 + 光晕脉冲
│ 中心亮点（静态白色菱）  │
│ 8 颗漂浮粒子           │  各自动画周期 2.5-3.5s
└──────────────────────┘
```

- 纯 CSS + Framer Motion，零图片依赖
- 整体尺寸 220×220px，375px 屏宽下不溢出

## 回顾

### 做了什么
把首页主视觉从"加载不出的牌面图片"换成纯 CSS 绘制的灵境之眼符号，同时优化了 tagline 和按钮文案。

### 为什么这么做
- 牌面图片加载不出是因为 HomePage 传的 card 对象缺少 `image` 字段。但与其修这个 bug，不如整体升级——首页用抽象符号建立品牌识别度，比展示某张具体的牌更有"高级感"。
- 旧 tagline "AI 塔罗 · 心灵之境" 只是在描述产品类型，新 tagline "解锁灵境，让心事皆有回响" 给出了行动召唤和情感价值。

### 学到什么
- 首页的第一视觉符号不一定是产品功能图示（塔罗牌），抽象品牌符号（星环）反而更能传递"质感"
- Framer Motion 的 `animate` 属性配合不同 `duration` 和 `ease` 可以做得很细腻，不需要额外依赖
