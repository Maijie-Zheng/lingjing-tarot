### 二、输入框

- **磨砂玻璃**：`backdrop-filter: blur(12px)` + 半透明背景 + 全边框
- **聚焦光效**：用 `isFocused` state 驱动边框颜色/光晕/背景三联动

  - 光晕：`box-shadow` 三层叠加，最远 60px
  - 背景：微微变亮
- **placeholder 呼吸**：CSS `@keyframes breathe`，opacity 0.3→0.6 循环 3s

### 三、问题 chip

- **点击反馈**：`whileTap scale: 0.97`
- **换一批**：点击时 emoji 旋转 360°，换内容时有 AnimatePresence stagger 退出/进入

## 回顾

### 做了什么
把输入页从"功能完善"打磨到"有灵境仪式感"。核心改动：输入框磨砂玻璃+聚焦光效、chip 分类标签+微交互、CTA 微光动画。

### 为什么这么做
用户反馈输入页"能跑通但不够有沉浸感"。输入框是用户说出心事的入口，这个时刻需要仪式感——聚焦光效暗示"灵境在聆听"，磨砂玻璃比纯黑块更有"灵境"质感。Chip 分类标签帮用户快速定位场景，降低选择成本。

### 学到什么
- `backdrop-filter: blur()` 在移动端性能可以接受，但需要加 `-webkit-backdrop-filter` 兼容
- 用 state 驱动聚焦样式比 CSS `:focus-within` 更可控（可以做更复杂的联动）
- Framer Motion 的 `whileHover`/`whileTap` 可以替代大量 CSS hover 样式
