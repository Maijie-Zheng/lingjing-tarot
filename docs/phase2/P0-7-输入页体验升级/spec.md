## 二、输入框升级

### 2.1 磨砂玻璃质感

当前：纯色半透明 `rgba(255,255,255,0.05)` + 底部边框

改为：
- 背景：`rgba(255,255,255,0.04)` + `backdrop-filter: blur(12px)`
- 边框：全边框 `1px solid rgba(255,255,255,0.08)`（替代纯底部边框）
- 圆角：`rounded-card`（12px，替代顶部圆角）
- 内阴影：`inset 0 1px 0 rgba(255,255,255,0.03)`

### 2.2 聚焦光效

点击输入框时：
- 边框颜色过渡为 `rgba(201,169,110,0.35)`（金色光晕）
- 外发光 `box-shadow: 0 0 24px rgba(201,169,110,0.08), 0 0 60px rgba(201,169,110,0.04)`
- 背景微微变亮 `rgba(255,255,255,0.06)`
- 过渡 0.4s ease

这些用 CSS `:focus-within` 实现，不需要 JS。

### 2.3 placeholder 呼吸动画

placeholder 文字做 3s 呼吸循环（opacity 0.3→0.6→0.3），像"低语"。

实现方式：用样式覆盖 `::placeholder` 的 opacity animation。注意：部分浏览器不支持 placeholder animation，降级时保持静态即可。

## 三、问题推荐区升级

### 3.1 按钮样式

当前：圆角 full 胶囊，金色半透明背景 + 金色边框

改为：
- 形状保持 `rounded-full`（已是胶囊形 ✅）
- 背景加深：`rgba(201,169,110,0.08)` → hover 时 `rgba(201,169,110,0.15)`
- 边框：`rgba(201,169,110,0.25)` → hover 时 `rgba(201,169,110,0.45)`
- **新增微光描边**：hover 时加 `box-shadow: 0 0 12px rgba(201,169,110,0.12)`
- 点击时：上浮 2px + 光晕扩散 + `scale: 0.97`

### 3.2 分类图标升级

当前使用的是 emoji：💕💼🌱✨

改为更有塔罗感的符号组合：

| 场景 | 旧图标 | 新图标 |
|------|--------|--------|
| 感情 | 💕 | 💫 |
| 事业 | 💼 | ⚡ |
| 自我 | 🌱 | 🌙 |
| 日常 | ✨ | 🔮 |

### 3.3 分类标签

在每个 chip 前显示分类小标签（文字 badge）：

```
💫 感情 · 他对我到底是什么感觉？
⚡ 事业 · 我该不该接受这个 offer？
🌙 自我 · 最近的整体运势怎么样？
🔮 日常 · 今天有什么需要留意的？
```

保持目前 `<span>{item.category}</span> {item.text}` 的格式即可。

### 3.4 "换一批"按钮

当前：🔄 + "换一批"文字

改为：
- 保持 emoji + 文字结构
- 点击时 emoji 做 360° 旋转动画（0.6s）
- 新增星芒旋转效果：按钮区域加一个极小的 CSS 旋转光环（点击时触发，0.5s）

## 四、CTA 按钮升级

### 4.1 状态变化

| 状态 | 表现 |
|------|------|
| 未输入（disabled） | `opacity: 0.35`，静态，不可点击 |
| 已输入（enabled） | 金色完整显示，带微光流动动画 |

### 4.2 微光流动动画

按钮启用后，加一个从左到右的"光带扫过"效果：
- 使用 `::after` 伪元素 + `@keyframes shimmer`
- 光带：白色半透明，宽 60px，从左到右扫过，周期 2.5s
- 仅在 enabled 状态播放

### 4.3 按钮文案

"✨ 开启灵境，为你抽牌"（替换 "🔮 开始抽牌"）
