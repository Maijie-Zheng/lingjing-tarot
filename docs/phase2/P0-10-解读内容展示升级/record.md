## 改动明细

### 一、ReadingText 模块化重写

#### 1.1 段落类型识别

新增 `getSectionType()` 函数，根据标题关键词识别 4 种段落类型：
- `narrative` — 含"整体叙事"
- `past` / `present` / `future` — 含"过去"/"现在"/"未来"
- `action` — 含"行动建议"

每种类型有独立的视觉配置（图标、标题覆盖、边框颜色）。

#### 1.2 磨砂玻璃容器

每个段落统一包裹在磨砂玻璃卡片中：
- 背景：`rgba(255,255,255,0.03)` + `blur(8px)`
- 边框：叙事/行动用白色微边框（`rgba(255,255,255,0.06)`），单牌解读用金色微边框（`rgba(201,169,110,0.1)`）
- 内阴影：`inset 0 1px 0 rgba(255,255,255,0.02)`

#### 1.3 标题区

| 段落类型 | 标题格式 | 示例 |
|---------|---------|------|
| 整体叙事 | ✨ 灵境总览 · 整体叙事 | 覆盖 AI 原标题 |
| 过去 | 🌙 过去 · 命运之轮 | 使用 AI 原标题 + emoji |
| 现在 | ✨ 现在 · 隐士 | 同上 |
| 未来 | 🌟 未来 · 星星 | 同上 |
| 行动建议 | 💫 行动建议 | 覆盖 AI 原标题 |

标题下方统一添加金色渐变分隔线：`linear-gradient(90deg, transparent, rgba(201,169,110,0.25), transparent)`。

#### 1.4 逆位标签

从 `text-red-400` 红色文字 → 金色描边胶囊：
- `border: 1px solid rgba(201,169,110,0.4)`
- `color: rgba(201,169,110,0.8)`
- `background: rgba(201,169,110,0.08)`
- `rounded-full px-2`

#### 1.5 叙事引导语

单牌解读正文开头自动添加引导句：
- 过去 → "回顾过去，{牌名}揭示了一段重要的信息——"
- 现在 → "聚焦当下，{牌名}映照出你此刻的内心状态——"
- 未来 → "展望未来，{牌名}指向一种可能的趋势——"

客户端自动生成，不修改 AI Prompt。

#### 1.6 牌名金色高亮

正文中出现的牌名（如"命运之轮""愚者""隐士"）自动用金色 `<span>` 包裹高亮，使用 `dangerouslySetInnerHTML` 实现。按牌名长度降序匹配，避免短名误匹配长名。

#### 1.7 分段动画节奏

| 段落 | 延迟 | 说明 |
|------|------|------|
| 整体叙事 | 80ms | 最先出现 |
| 过去 | +350ms | 累计 430ms |
| 现在 | +600ms | 累计 1030ms |
| 未来 | +600ms | 累计 1630ms |
| 行动建议 | +350ms | 累计 1980ms |

每段入场：`fadeIn + slideUp`（duration 0.55s）。

#### 1.8 行动建议条目化

行动建议段落拆分为独立条目，每条 staggered 入场（`initial={{ opacity: 0, x: -8 }}`，延迟 0.12s 递增）。

#### 1.9 模块间分隔符

从 `#` + 纯渐变线 → ✦ 金色星芒字符（带呼吸闪烁）：
```jsx
<span style={{ color: 'rgba(201,169,110,0.3)' }}>
  ✦
</span>
```

### 二、ReadingPage 新增功能

#### 2.1 卡牌放大模态框

- 点击解读区卡牌 → 全屏暗色遮罩（`rgba(0,0,0,0.6)` + `blur(4px)`）

2. 左下紫色光斑（250px，`rgba(139,92,246,0.03)`，22s 循环漂移）

## 回顾

### 做了什么
将解读内容展示从"纯文字平铺"升级为"沉浸式阅读体验"。ReadingText 从单一文字组件重写为模块化系统：整体叙事/单牌解读/行动建议三大模块各用磨砂玻璃容器包裹、金色标题+分隔线、逆位标签改为金色胶囊、正文牌名自动高亮、叙事引导语自动生成。ReadingPage 新增卡牌点击放大模态框和漂浮光斑背景。

### 为什么这么做
- 解读内容是用户体验的核心——好内容需要好容器来承载，磨砂玻璃模块让内容有了"作品感"
- 逆位标签用红色是前序界面的遗留问题——红色=错误/警告的心理暗示，金色=神秘/能量，更符合塔罗品牌调性
- 引导语让 AI 的解读有了"人味"——用户感觉灵境在认真讲述，而不是冰冷的文本输出
- 卡牌放大让用户能看清牌面细节——22 张大阿卡纳的韦特塔罗画面本身就是艺术品
- 模块间 ✦ 分隔比 `#` 或纯渐变线更有塔罗仪式感
- 分段动画的非均匀节奏模仿了真实占卜师的"先总后分"的解读节奏

### 学到什么
- 好的内容展示不只是排版——磨砂玻璃容器的使用让每个模块都有了"仪式感容器"，和单纯的白色卡片完全不同
- 金色描边胶囊比红色文字更适合"逆位"这样的神秘学概念——颜色心理学在塔罗场景下特别重要
- 客户端文本增强（牌名高亮、引导语）可以在不改 AI Prompt 的情况下大幅提升阅读体验
- 分段动画的节奏设计比匀速播放更有"人在慢慢讲"的感觉
- ✦ 星芒作为分隔符和塔罗品牌高度契合——比普通线条多了一层神秘含义
