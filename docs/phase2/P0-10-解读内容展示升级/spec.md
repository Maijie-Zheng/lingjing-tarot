## 一、ReadingText 模块化重写

### 1.1 段落类型识别

AI 返回的 `【XXX】` 标记段落被解析后，按标题关键词分 4 种类型：

| 类型 | 关键词 | 视觉处理 |
|------|--------|---------|
| `narrative` | 含"整体叙事" | 全宽纯文字，标题覆盖为"✨ 灵境总览 · 整体叙事" |
| `past` | 含"过去" | 图文并茂（牌面+文字），匹配过去位置的牌 |
| `present` | 含"现在" | 同上，匹配现在位置的牌 |
| `future` | 含"未来" | 同上，匹配未来位置的牌 |
| `action` | 含"行动建议" | 条目化展示，标题覆盖为"💫 行动建议" |

### 1.2 磨砂玻璃容器

每个段落统一包裹在磨砂玻璃卡片中（对齐 AskPage 输入框、ShufflePage "你在问"卡）：

```
background: rgba(255,255,255,0.03)
backdrop-filter: blur(8px)
border: 1px solid {按类型}
  - 叙事/行动：rgba(255,255,255,0.06)
  - 单牌解读：rgba(201,169,110,0.1)  ← 金色微边框暗示"核心内容"
box-shadow: inset 0 1px 0 rgba(255,255,255,0.02)
border-radius: 12px
padding: 16px
```

### 1.3 标题区

```
┌─────────────────────────────────┐
│ ✨ 灵境总览 · 整体叙事           │  ← text-brand-gold, font-serif, 16px
│ ─────────────────────────────── │  ← 金色渐变线
│                                 │
│ （正文内容）                     │
└─────────────────────────────────┘
```

- 标题金色衬线体（`text-brand-gold text-base font-serif font-semibold`）
- emoji 前缀：🌙（过去）/ ✨（现在）/ 🌟（未来）/ 💫（行动建议）/ ✨（整体叙事）
- 逆位牌标题行末追加**金色描边胶囊**标签

**逆位标签**（从红色改为金色）：
```
border: 1px solid rgba(201,169,110,0.4)
color: rgba(201,169,110,0.8)
background: rgba(201,169,110,0.08)
border-radius: 9999px, padding: 2px 8px
font-size: 12px
```
> 红色在 UI 心理中 = 错误/警告；金色 = 神秘/能量/特殊状态。逆位不是"负面"，是"另一种角度"。

**标题下方分隔线**：
```
height: 1px
background: linear-gradient(90deg, transparent, rgba(201,169,110,0.25), transparent)
```

### 1.4 叙事引导语

单牌解读正文开头自动添加引导句（客户端生成，不改 Prompt）：

| 位置 | 引导语 |
|------|--------|
| 过去 | 回顾过去，{牌名}揭示了一段重要的信息—— |
| 现在 | 聚焦当下，{牌名}映照出你此刻的内心状态—— |
| 未来 | 展望未来，{牌名}指向一种可能的趋势—— |

引导语 + 空行 + AI 原文 = 最终显示内容。

### 1.5 牌名金色高亮

正文中出现的牌名（如"命运之轮""愚者""隐士"）自动包裹 `<span class="text-brand-gold font-medium">`。

实现方式：`dangerouslySetInnerHTML` + 正则替换。按牌名长度降序匹配，避免"愚者"误匹配"愚者逆位"的部分。仅匹配独立词（前后非字母数字字符）。

### 1.6 单牌解读图文布局

```
┌─────────────────────────────────┐
│                                 │
│  ┌──────┐  🌙 过去 · 命运之轮   │
│  │      │  ─────────────────    │
│  │ 牌面 │                       │
│  │      │  回顾过去，命运之轮    │
│  │ 悬浮 │  揭示了一段重要的信息  │
│  │ +光晕│  ——                    │
│  └──────┘  （AI 原文...）       │
│                                 │
└─────────────────────────────────┘
```

- 牌面：`TarotCard size="md"` + 外层 wrapper 金色光晕（`0 0 16px rgba(201,169,110,0.2)`）+ 浮动动画（`y: [0, -4, 0]`, 4s 循环）
- 牌面 `onClick` → 触发全屏放大模态框
- 文字区 `flex-1`，保持 `whitespace-pre-line` 换行

### 1.7 行动建议条目化

```
┌─────────────────────────────────┐
│ 💫 行动建议                      │
│ ─────────────────────────────── │
│                                 │
│ 🌟 第一条建议...                 │  ← 每条 staggered 入场
│                                 │  ← (x: -8 → 0, delay 0.12s/条)
│ 💫 第二条建议...                 │
│                                 │
│ 🌙 第三条建议...                 │
│                                 │
└─────────────────────────────────┘
```

- 按空行拆分 `actionItems`
- 每条 `motion.div` staggered 入场

### 1.8 模块间分隔

```
（卡片结束）
        ✦          ← 金色星芒，呼吸闪烁
（下一卡片开始）
```

替代之前 `#` 符号和纯渐变线。✦ 字符携带塔罗/神秘学联想，呼吸动画暗示"能量在流动"。

### 1.9 分段动画节奏

不再等间隔匀速出现，改为模拟"占卜师先总后分"的解读节奏：

| 段落 | 延迟（累积） | 理由 |
|------|------------|------|
| 整体叙事 | 80ms | 先给全局视角 |
| 过去 | 430ms | 停顿一下，开始讲第一张 |
| 现在 | 1030ms | 给用户消化第一段的时间 |
| 未来 | 1630ms | 同上 |
| 行动建议 | 1980ms | 最后给出方向 |

每段入场动画：`opacity 0→1 + y 16→0`，duration 0.55s，easeOut。

## 二、卡牌放大模态框

### 交互

1. 用户点击解读区卡牌 → 全屏暗色遮罩出现
2. 卡牌放大到 `lg` 尺寸（140×210），居中
3. 三层金色光晕环绕卡牌
4. 点击遮罩或卡牌 → 关闭
5. 底部提示"轻触任意处关闭"（延迟 0.3s 出现）

### 视觉规格

```
遮罩层：
  background: rgba(0,0,0,0.6)
  backdrop-filter: blur(4px)

卡牌容器：
  border-radius: 16px
  box-shadow:
    0 0 30px rgba(201,169,110,0.3)    ← 紧贴光晕
    0 0 80px rgba(201,169,110,0.1)    ← 中距离扩散
    0 0 120px rgba(201,169,110,0.04)  ← 远距离光晕

入场动画：scale 0.85→1 + opacity 0→1 (0.3s, easeOut)
退场动画：scale 1→0.85 + opacity 1→0 (0.3s)
```

## 三、背景氛围增强

### 漂浮光斑

在 ReadingPage 内容区背后叠加 2 个缓慢漂移的光斑：

| 光斑 | 颜色 | 尺寸 | 位置 | 动画周期 |
|------|------|------|------|---------|
| 右上 | 金色 `rgba(201,169,110,0.03)` | 300px | `right: -10%, top: 15%` | 18s 循环漂移 |
| 左下 | 紫色 `rgba(139,92,246,0.03)` | 250px | `left: -8%, top: 55%` | 22s 循环漂移 |

- `position: fixed`, `pointer-events: none`, `z-index: 0`
- 漂移动画使用 Framer Motion `x/y/opacity` 多点关键帧
- 不修改 StarBackground（全局背景保持 40 颗粒子）

### 原有光晕（P0-9 保留）

页面中央 400px 紫色径向渐变光晕，4s 呼吸：loading 时 `opacity: [0.5, 1, 0.5]`，ready 后降为 `0.4`。
