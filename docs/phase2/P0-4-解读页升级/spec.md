# P0-4 · 解读页视觉升级 — 规格说明

> 状态：📝 待确认 | 日期：2026/06/09 | 属于：第二阶段 → 视觉升级

---

## 一、现状

| 维度 | 当前状态 |
|------|---------|
| 牌面展示 | 3 张 sm (64×96) 缩略图并排顶部 |
| 解读展示 | 纯文字逐段淡入，牌面和解读者分离 |
| Prompt 语言 | 偏冗长，80-150 字/段 |
| 用户感受 | "牌太小、看不到牌面、没有图文并茂、AI 太啰嗦" |

### 当前布局

```
┌──────────────────────────┐

│  「问题」                 │
├──────────────────────────┤

│  【过去·愚者】            │  ← 看不到牌
│  纯文字...               │
│  【现在·月亮】            │
│  纯文字...               │
│  ...                    │
└──────────────────────────┘
```

---

## 二、目标

1. **牌面大起来**：每张牌在解读中 md 尺寸（100×150），配上位置标签
2. **图文并茂**：牌面图片和对应文字放在一起，用户边看牌边读解读
3. **AI 更直接**：System Prompt 调优，减少废话，直击核心

### 3.3 ReadingPage 改动细节

```
改动前：
  - 3 张 sm 牌顶部一行
  - 分隔线
  - <ReadingText rawText={...} />

改动后：
  - 整体叙事（全宽文字，无牌面）
  - 3 组牌+解读（md 牌左 + 文字右）
  - 行动建议（全宽文字）
  - 去掉顶部 3 张缩略图
```

### 3.4 ReadingText 改动细节

新增 `cards` prop：

```jsx
<ReadingText
  rawText={readingText}
  cards={cards}       // 🆕 可选：传入牌数据以显示牌面
  speed={800}
/>
```

当有 `cards` 时：
- 解析每个段落标题，匹配牌名（如「过去·愚者」→ 找到对应 card）
- 匹配到的段落显示为"左侧牌面 + 右侧文字"的横向布局
- 未匹配的段落（整体叙事、行动建议）保持全宽纯文字

### 3.5 System Prompt 调优

```diff
- 【整体叙事】用 100-150 字讲述三张牌串联起来的故事
+ 【整体叙事】用 60-80 字，一句话概括三张牌的串联故事。直击核心，不铺垫。

- 【过去 · {牌名}】80-120 字
+ 【过去 · {牌名}】60-80 字。直说这张牌在告诉用户什么，不要绕弯子。

- 【现在 · {牌名}】80-120 字
+ 【现在 · {牌名}】60-80 字。

- 【未来 · {牌名}】80-120 字
+ 【未来 · {牌名}】60-80 字。

+ 新增约束：
+ - 每段开头直接给结论，不要"这张牌暗示着..."之类的套话
+ - 用日常对话的语气，不要书面化的长句
```
