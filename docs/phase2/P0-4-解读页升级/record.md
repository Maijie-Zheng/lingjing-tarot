## 一、实际改动

| 文件 | 改动 | 说明 |
|------|------|------|
| `src/utils/promptBuilder.js` | 🔧 System Prompt 调优 | 更直接、更短、去套话 |
| `src/components/ReadingText.jsx` | 🔧 新增 `cards` prop | 图文并茂配对布局 |
| `src/pages/ReadingPage.jsx` | 🔧 布局重做 | 去掉顶部缩略图 + 传 cards 给 ReadingText |

### promptBuilder.js 改动细节

```
改动前                                改动后
─────────────────────────────────    ─────────────────────────────────
【整体叙事】100-150 字               【整体叙事】50-70 字
【过去·X】80-120 字                  【过去·X】60-80 字
【现在·X】80-120 字                  【现在·X】60-80 字
【未来·X】80-120 字                  【未来·X】60-80 字

新增约束：
  - 开门见山给结论，不绕弯子
  - 每段开头直接给结论，不要"这张牌暗示着..."套话
  - 用日常对话语气，不要书面化长句
```

### ReadingText.jsx 改动细节

```
改动前：
  - Props: rawText, speed
  - 全部段落都是标题+文字垂直排列

改动后：
  - Props: rawText, cards（可选）, speed
  - 新增 matchCard() 函数：根据段落标题匹配牌数据
  - 匹配到的段落：左牌(md) + 右文 横向布局
    ├── 左侧：TarotCard md (100×150)
    └── 右侧：emoji + 位置标签 + 牌名 + 逆位标签 + 正文
  - 未匹配的段落（整体叙事、行动建议）：全宽纯文字
```

### ReadingPage.jsx 改动细节

```
改动前：
  - 3 张 sm 缩略图置于顶部
  - 分隔线
  - <ReadingText rawText={...} />

改动后：
  - 顶部缩略图区域 → 删除
  - 分隔线 → 删除
  - <ReadingText rawText={...} cards={cards} /> → 传入 cards
  - 删除未使用的 TarotCard import
```
