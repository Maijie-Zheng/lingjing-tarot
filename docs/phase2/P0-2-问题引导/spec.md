# P0-2 · 问题引导优化 — 规格说明

> 状态：📝 待确认 | 日期：2026/06/09 | 属于：第二阶段 → 仪式感提升

---

## 一、现状

| 维度 | 当前状态 |
|------|---------|
| 问题示例数量 | 8 条固定文案，每次随机显示 5 条 |
| 刷新机制 | **无**——用户进来看到什么就是什么，不能换 |
| 交互反馈 | 无动画，选中 chip 直接填入 |
| 用户感受 | "引导度不够，想换一批看看但没有按钮" |

### 当前代码逻辑（AskPage.jsx）

```javascript
// 8 条固定示例 → 进入页面时随机挑 5 条 → 存进 useState 不再变
const EXAMPLE_QUESTIONS = [ /* 8 条 */ ]
function pickExamples() {
  return [...EXAMPLE_QUESTIONS].sort(() => Math.random() - 0.5).slice(0, 5)
}
const [examples] = useState(() => pickExamples())  // ← 再也不会变
```

### 问题分析

1. **数量太少**：8 条中取 5 条，用户能看到的组合太少，缺乏"探索感"
2. **不能刷新**：没有换一批按钮，用户不满意当前示例就没法换
3. **无动画**：chip 突然出现，缺少"灵感涌现"的感觉
4. **分类缺失**：所有示例堆在一起，没有按场景分类（感情/事业/自我）

---

## 二、目标

1. **扩充题库**：从 8 条 → **20 条**，覆盖感情/事业/自我/日常 4 个场景
2. **随机刷新**：新增"🔄 换一批"按钮，每次随机换 5 条，有动画
3. **场景分类**：chip 左侧加小 emoji 类别标签，让用户快速识别
4. **动画反馈**：刷新时 chip 有淡入淡出 + 位移效果

### 3.2 交互行为

| 行为 | 描述 |
|------|------|
| **初始加载** | 随机选 5 条显示，chip 带淡入动画（stagger 50ms） |
| **点击"换一批"** | chip 先淡出 → 换内容 → 重新淡入（Framer Motion `AnimatePresence`） |
| **点击 chip** | 填入输入框（行为不变） |
| **按钮位置** | 示例 chip 区域的右上角，与"试试这些问题："同行 |

### 3.3 代码改动范围

| 文件 | 改动 |
|------|------|
| `src/pages/AskPage.jsx` | 改数据结构 + 加刷新按钮 + 加 stagger 动画 |

**只改一个文件。** 不改 `src/components/` 下的任何组件。

### 3.4 动画细节

```
初始进入：5 个 chip 依次淡入（每个延迟 50ms）
换一批：
  1. 旧 chip 同时淡出（200ms）
  2. 等待旧 chip 完全消失
  3. 新 chip 依次淡入（每个延迟 50ms）

使用 Framer Motion：
  - <AnimatePresence mode="wait"> 包裹 chip 容器
  - 每个 chip 用 motion.button
  - initial={{ opacity: 0, y: 8 }}
  - animate={{ opacity: 1, y: 0 }}
  - exit={{ opacity: 0, y: -8 }}
```
