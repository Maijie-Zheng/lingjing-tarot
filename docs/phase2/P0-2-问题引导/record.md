### AskPage.jsx 改动细节

```
改动前：
  - 8 条纯文字示例，每次随机 5 条
  - useState(() => pickExamples()) — 进入后不再变
  - 无刷新按钮、无动画

改动后：
  - 20 条示例，4 个分类（💕感情 / 💼事业 / 🌱自我 / ✨日常）
  - 每条带 category emoji
  - "🔄 换一批"按钮（右上角）
  - 刷新时：🔄 图标旋转 360° → 旧 chip 淡出 → 新 chip 依次淡入（stagger 50ms）
  - 首次进入也有 stagger 入场动画
```
