# P0-9 解读页体验升级 · 规格说明

> 状态：待 Review | 日期：2026-06-09

---

## 目标

把解读页的加载等待体验从"简单转圈"升级到"灵境仪式感 AI 读取"。覆盖问题卡片品牌化、加载动画沉浸化、进度指示器信息可视化、背景氛围增强、重新抽牌 bug 修复五个维度。

---

## 改动范围

| 文件 | 改动类型 |
|------|----------|
| `src/pages/ReadingPage.jsx` | 大量重写：问题卡片磨砂化 + 集成新 Loading + 进度指示器 + 修复重新抽牌 bug |
| `src/components/LoadingSpinner.jsx` | 完全重写：星轨旋转 + 牌面浮现 + 诗意文案轮换 |

---

## 一、Bug 修复：重新抽牌不保留问题

**问题**：`<Link to="/shuffle">` 不传问题参数，ShufflePage 读到 null 显示"未提供问题"。

**修复**：改用 `navigate(`/shuffle?q=${encodeURIComponent(question)}`)`，和 AskPage→ShufflePage 跳转方式一致。

---

## 二、顶部问题展示区

### 当前
纯文字 `"你问的是「问题」"`，和前面页面的磨砂玻璃卡片风格脱节。

### 改为
磨砂玻璃卡片（和 AskPage 输入框、ShufflePage "你在问"卡同款风格）：
- 背景：`rgba(255,255,255,0.04)` + `backdrop-filter: blur(12px)`
- 边框：`1px solid rgba(255,255,255,0.08)`
- 内阴影：`inset 0 1px 0 rgba(255,255,255,0.03)`
- 文字层级："你问的是"（`text-white/30 text-xs`）+ 问题（`text-white/80 text-sm`，不加引号）
- 入场动画：motion.div fadeIn + slideDown

---

## 三、核心加载区：星轨仪式感动画

### 当前
简单环形 spinner + 🃏 emoji + 4 条轮换文案 + 3 个金色呼吸点

### 改为三层动画组合

#### 3.1 星轨双环
- 2 个同心圆环（`border-radius: 50%`，`border: 1px solid rgba(201,169,110,0.15)`）
- 大环 200px / 小环 150px
- 两环以不同速度旋转（大环 10s / 小环 7s，`linear` 无限循环）
- 每环 3-4 颗金色光点标记（4px，`rgba(201,169,110,0.6)`，带微光晕）
- 环整体 opacity 呼吸变化（4s 循环）

#### 3.2 塔罗牌浮现（中心）
- 一张 TarotCard 牌背（lg，140×210）居中
- 上下微浮动（`y: [0, -6, 0]`，3.5s 循环）
- 极淡金色外发光：`0 0 30px rgba(201,169,110,0.15), 0 0 60px rgba(201,169,110,0.06)`
- 8 颗微型星点粒子从四周向牌面汇聚再散开（2.5s 循环）

#### 3.3 诗意文案轮换

| 旧 | 新 |
|----|-----|
| "✨ 牌面正在连接你的心灵..." | "✨ 灵境读取中，牌意正在浮现…" |
| "🔮 观察牌面中..." | "🔮 三张牌正在低语，讲述你的故事…" |
| "🌙 聆听你的故事..." | "🌙 倾听你心底的声音…" |
| "💫 解读正在生成..." | "💫 星图已显现，解读即将揭晓…" |

AnimatePresence mode="wait" 淡入淡出切换（2.5s 间隔）。

#### 3.4 中心光晕
- 星轨背后大型径向渐变光晕（`rgba(139,92,246,0.05)`，直径约 400px）
- 呼吸动画 3s 循环

---

## 四、底部进度指示器

在 loading 状态显示，3 个位置指示器对应过去/现在/未来：

```
  🌙           ✨           🌟
过去·溯源    现在·当下    未来·趋势
```

- 3 个指示器全部做呼吸闪烁（不同相位延迟制造"波浪"效果）
- 表示"AI 正在逐一读取三张牌"
- Loading 完成后淡出消失

---

## 五、解读完成后过渡

- LoadingSpinner 用 AnimatePresence exit 淡出（0.4s）
- 进度指示器同时淡出
- ReadingText 内容 fadeIn（0.5s，保持现有动画）

---

## 六、背景氛围增强

- 页面中央位置径向渐变圆形光晕（`rgba(139,92,246,0.04)`，直径约 400px）
- 呼吸动画 4s 循环
- 加载完成后减弱但保留（opacity 减半），作为背景氛围
