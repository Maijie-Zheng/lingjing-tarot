## 改动明细

### 一、Bug 修复：重新抽牌不保留问题

**问题**：`<Link to="/shuffle">` 不传问题参数，ShufflePage 的 `searchParams.get('q')` 读到 null，显示"未提供问题"。

**修复**：改为 `navigate(`/shuffle?q=${encodeURIComponent(question)}`)`，和 AskPage→ShufflePage 跳转方式一致。按钮改为 `<button>` + onClick。

### 二、问题展示卡

当前纯文字 → 磨砂玻璃卡片（和 AskPage 输入框、ShufflePage "你在问"卡同款）：
- 背景：`rgba(255,255,255,0.04)` + `backdrop-filter: blur(12px)`
- 边框：`1px solid rgba(255,255,255,0.08)`
- 内阴影：`inset 0 1px 0 rgba(255,255,255,0.03)`
- 文字层级："你问的是" `text-white/30 text-xs` + 问题 `text-white/80 text-sm`（不加引号）
- 入场动画：fadeIn + slideDown

### 三、Loading 星轨仪式感动画（LoadingSpinner 完全重写）

**旧**：简单环形 spinner + 🃏 emoji + 4 条轮换文案 + 3 个金色呼吸点

**新**：三层动画组合

| 层 | 内容 | 动画 |
|----|------|------|
| 中心光晕 | 400px 径向渐变紫色光晕 | opacity 呼吸，3s 循环 |
| 星轨双环 | 外环(200px, 5 光点) + 内环(150px, 4 光点) | 外环 10s 正向旋转，内环 7s 反向旋转，opacity 呼吸 |
| 牌面浮现 | TarotCard lg 牌背居中 | y 轴上下微浮动 3.5s + 金色外发光 |
| 星点粒子 | 8 颗金色光点 | 从四周向牌面汇聚再散开，2.5s 循环 |
| 诗意文案 | 4 条新文案 | AnimatePresence 淡入淡出，2.5s 间隔 |
| 进度指示器 | 过去/现在/未来 3 组 emoji+标签 | 相位差呼吸闪烁（波浪效果） |

**文案升级**：

## 回顾

### 做了什么
把解读页的等待体验从"转圈等待"升级为"灵境仪式感 AI 读取"。LoadingSpinner 从简单转圈改为星轨双环旋转 + 牌面浮现 + 星点汇聚 + 诗意文案轮换。问题卡片从纯文字改为磨砂玻璃卡片。修复了"重新抽牌"按钮丢失问题参数的 bug。新增背景光晕增强氛围。

### 为什么这么做
- 塔罗解读的等待过程本身就是仪式感的一部分——用户等待 AI 生成解读时，应该感觉"灵境正在为我认真读取牌意"，而不是"系统在加载数据"
- 星轨、牌面浮现、星点汇聚这些视觉元素和塔罗/灵境品牌强关联，让等待从焦虑变为沉浸
- 问题卡片磨砂化是和前序页面品牌语言保持一致的必要步骤
- "重新抽牌"保留问题是基础用户体验——用户已经输入了问题，不应该因为想换牌而丢失问题

### 学到什么
- 加载动画是用户等待体验的核心——好的加载动画能大幅降低等待焦虑，甚至让用户享受等待
- 星轨双环的反向旋转 + 不同速度制造了很好的"星盘运转"视觉效果
- 进度指示器的相位差呼吸（延迟 0/0.4/0.8s）比同步闪烁更有"逐一读取"的感觉
- 磨砂玻璃设计语言贯穿所有页面后，品牌的统一感明显提升
- Framer Motion 的 `AnimatePresence mode="wait"` 做状态切换过渡非常流畅
