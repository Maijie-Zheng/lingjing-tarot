# 灵境 · PRD 产品需求文档

> 文档状态：V1.0 初稿 | 最后更新：2026/06/09 | 作者：@Y9000 + AI协助
>
> 📐 本文档是灵境 MVP 的唯一需求来源。开发、设计、测试均以此为准。

---

## 一、文档概览

### 1.1 产品信息

| 项目 | 内容 |
|------|------|
| 产品名称 | 灵境 |
| 产品类型 | AI 塔罗解读 Web App |
| MVP 版本 | V1.0 |
| 目标平台 | 移动端 Web（手机浏览器、微信内嵌浏览器） |
| 技术栈建议 | React / Vue + Vercel 部署 + OpenAI/DeepSeek API |

### 1.2 核心验证问题

> **用户觉得 AI 解读"懂自己"吗？**

### 1.3 MVP 一句话

> 输入问题 → 选 3 张牌 → AI 解读 + 行动建议 → 分享精美卡片。不登录，不付费。

---

## 二、用户故事（User Stories）

| ID | 作为 | 我想要 | 以便 |
|----|------|--------|------|
| US-01 | 用户 | 在首页看到一个有氛围感的入口 | 被吸引并愿意开始体验 |
| US-02 | 用户 | 输入自己真实的问题 | AI 能针对我的具体问题给出解读 |
| US-03 | 用户 | 看到问题引导示例 | 当我不确定问什么时，能得到启发 |
| US-04 | 用户 | 洗牌时有动画和音效 | 感受到"正在为我准备"的仪式感 |
| US-05 | 用户 | 从牌背中亲手选出 3 张牌 | 有参与感，觉得"是我选的" |
| US-06 | 用户 | 翻牌时有翻转动画 | 体验期待感和惊喜感 |
| US-07 | 用户 | 获得一份贴合我问题的个性化解读 | 觉得"被理解"而不是"被模板回复" |
| US-08 | 用户 | 获得 2-3 条具体可落地的行动建议 | 不只是"知道了"，而是"知道怎么做了" |
| US-09 | 用户 | 把解读结果生成精美图片分享给朋友 | 和朋友讨论，同时也帮产品传播 |
| US-10 | 用户 | 回看之前的解读记录 | 回顾自己的心路历程 |
| US-11 | 用户 | 删除某条不想保留的记录 | 隐私可控 |
| US-12 | 用户 | 不需要注册/登录就能使用全部功能 | 零门槛，且隐私安全 |

## 三、页面结构

### 3.1 页面地图

```
灵境 MVP 共 6 个页面（4 个核心页面 + 2 个辅助页面）：

┌────────┐
│  首页   │  ← 核心页面 1
└───┬────┘
    ↓
┌────────────┐
│ 问题输入页  │  ← 核心页面 2
└───┬────────┘
    ↓
┌────────────┐
│ 洗牌选牌页  │  ← 核心页面 3
└───┬────────┘
    ↓
┌────────────┐
│ AI 解读页   │  ← 核心页面 4
└───┬────────┘
    ├→ 分享卡片（系统分享弹窗）
    └→ 保存到历史记录
             ↓
        ┌──────────┐
        │ 历史记录页 │  ← 辅助页面
        └──────────┘
```

### 3.2 页面导航

| 路径 | 页面名称 | 进入方式 |
|------|---------|---------|
| `/` | 首页 | 直接访问 |
| `/ask` | 问题输入页 | 首页点击"开始" |
| `/shuffle` | 洗牌选牌页 | 输入问题后点击"开始抽牌" |
| `/reading` | AI 解读页 | 选完 3 张牌后自动跳转 |
| `/history` | 历史记录页 | 首页点击"历史记录"图标 |
| `/share` | （无独立页面） | 解读页点击"分享"触发系统分享弹窗 |

## 四、页面详细设计

---

### 4.1 首页（`/`）

#### 页面目标
3 秒内建立情绪氛围，让用户产生"想试试"的冲动。

#### 页面布局

```
┌──────────────────────────┐
│                          │
│         ✨ 星空背景       │
│      （缓慢飘动的粒子）    │
│                          │
│      🃏 一张主视觉牌面     │
│     （缓慢浮动，微旋转）    │
│                          │
│      灵  境              │
│    AI 塔罗 · 心灵之境     │
│                          │
│   ┌──────────────────┐   │
│   │    ✨ 开始抽牌     │   │  ← 主 CTA 按钮，紫色渐变
│   └──────────────────┘   │
│                          │
│   📜 历史记录            │  ← 文字链接，右上角
│                          │
│   一句话：               │
│   "让塔罗倾听你的心事"    │
└──────────────────────────┘
```

#### 交互规则

| 元素 | 行为 |
|------|------|
| 星空背景 | 进入页面即开始缓慢飘动，粒子数量 30-50，颜色为金色/白色 |
| 主视觉牌面 | 随机展示一张塔罗牌（The Star / The Moon 等柔和牌面），缓慢上下浮动 ±10px，3s 循环 |
| "开始抽牌"按钮 | hover 时微微放大（scale 1.05），点击后页面过渡到 `/ask` |
| "历史记录"链接 | 点击进入 `/history`；如果无历史记录，显示空状态 |
| 整体过渡动画 | 页面间 fade 过渡，时长 400ms |

#### 设计规范

| 属性 | 值 |
|------|-----|
| 背景色 | 深紫渐变 `#1a0a2e → #0d0221` |
| 主色调 | 金色 `#c9a96e` |
| 字体 | 标题用衬线体（如 Noto Serif SC），正文用无衬线 |
| 粒子效果 | CSS animation 或 Canvas，性能需兼容低端手机 |

### 4.2 问题输入页（`/ask`）

#### 页面目标
让用户舒服地说出自己真实的心事。

#### 页面布局

```
┌──────────────────────────┐
│  ← 返回                   │
│                          │
│  "此刻，你在想什么？"       │  ← 引导文案，衬线体
│                          │
│  ┌──────────────────┐    │
│  │                  │    │
│  │  （输入框）       │    │  ← Textarea，无边框，底部下划线
│  │                  │    │     最小 3 行，最大可见 6 行
│  │                  │    │     placeholder: "写下你的心事..."
│  └──────────────────┘    │
│                          │
│  试试这些问题：            │
│  ┌──────────┐ ┌──────────┐ │
│  │他对我什么 │ │我该不该   │ │  ← 问题示例标签（chip），点击填入输入框
│  │感觉？    │ │跳槽？    │ │
│  └──────────┘ └──────────┘ │
│  ┌──────────┐ ┌──────────┐ │
│  │最近运势   │ │这段关系   │ │
│  │怎么样？   │ │会怎样？   │ │
│  └──────────┘ └──────────┘ │
│                          │
│   ┌──────────────────┐   │
│   │    🔮 开始抽牌     │   │  ← 主按钮，输入为空时置灰不可点击
│   └──────────────────┘   │
│                          │
│  🔒 你的问题只保存在你的手机里 │  ← 隐私提示，小字灰色
└──────────────────────────┘
```

#### 交互规则

| 元素 | 行为 |
|------|------|
| 输入框 | 自动聚焦（延迟 300ms）；支持换行；最多 200 字，右下角显示字数 `当前/200`（超过 50 字才显示计数）；无内容时主按钮置灰 |
| 问题示例 chip | 点击后将示例文字填入输入框（替换而非追加）；5 个示例随机显示（每次刷新变化，增加新鲜感） |
| "开始抽牌"按钮 | 输入框有内容（非纯空格）时高亮可点击；点击后跳转 `/shuffle` 并携带问题参数；点击时按钮文字变为"✨ 洗牌中..." |
| 返回按钮 | 点击后回到首页，输入内容不保存 |
| 键盘 | 点击输入框外区域收起键盘 |

#### 问题示例库（共 8 条，每次随机显示 5 条）

```
1. 他对我到底是什么感觉？
2. 我该不该接受这个 offer？
3. 最近的整体运势怎么样？
4. 这段关系应该继续还是放手？
5. 为什么我总觉得很焦虑？
6. 我适合现在转行吗？
7. 接下来三个月有什么需要注意的？
8. 我和 TA 能走到一起吗？
```

#### 设计规范

| 属性 | 值 |
|------|-----|
| 输入框背景 | 半透明白色 `rgba(255,255,255,0.05)` |
| Chip 背景 | 半透明金色 `rgba(201,169,110,0.15)`，边框 `rgba(201,169,110,0.3)` |
| 隐私提示 | `font-size: 12px`, `color: rgba(255,255,255,0.4)` |

### 4.3 洗牌选牌页（`/shuffle`）⭐ 核心体验

#### 页面目标
这是灵境仪式感的灵魂。让用户感觉自己正在参与一场神秘的仪式，而不是"点了个按钮"。

#### 阶段一：洗牌（3 秒）

```
┌──────────────────────────┐
│                          │
│      "正在为你洗牌..."     │
│                          │
│   ┌─┐ ┌─┐ ┌─┐ ┌─┐      │
│   │🃏│ │🃏│ │🃏│ │🃏│      │  ← 4-5 张牌背快速交替滑动
│   └─┘ └─┘ └─┘ └─┘      │     来回穿插，模拟洗牌
│                          │
│       ✨ 音效：洗牌声      │
│                          │
│   [进度条：洗牌中...]      │
└──────────────────────────┘
```

#### 阶段二：选牌（用户操作）

```
┌──────────────────────────┐
│                          │
│  "请凭直觉，选出 3 张牌"    │
│   已选：2 / 3             │
│                          │
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐    │
│  │🃏│ │🃏│ │🃏│ │🃏│    │
│  └──┘ └──┘ └──┘ └──┘    │
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐    │  ← 8-12 张牌背，排列成 2-3 行
│  │🃏│ │🃏│ │🃏│ │🃏│    │
│  └──┘ └──┘ └──┘ └──┘    │     （数量可配，建议 9 张 3×3）
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐    │
│  │🃏│ │🃏│ │🃏│ │🃏│    │
│  └──┘ └──┘ └──┘ └──┘    │
│                          │
│   第 1 张：代表"过去"      │  ← 提示当前在选第几张、这个位置的含义
│                          │
│  ┌──────────────────┐    │
│  │   确认这三张牌 🔮  │    │  ← 选满 3 张后亮起
│  └──────────────────┘    │
└──────────────────────────┘
```

#### 阶段三：翻牌（动画）

```
选满 3 张 → 点击确认 → 已选牌放大居中
→ 第 1 张翻转（3D rotateY 动画，0.6s）→ 显示牌面 + 位置标签"过去"
→ 停顿 0.5s
→ 第 2 张翻转 → 显示牌面 + 位置标签"现在"
→ 停顿 0.5s
→ 第 3 张翻转 → 显示牌面 + 位置标签"未来"
→ 停顿 0.8s
→ 自动跳转 `/reading` 并携带：用户问题 + 3 张牌信息
```

#### 交互规则

| 元素 | 行为 |
|------|------|
| 洗牌动画 | 自动播放 2-3 秒，牌背快速来回交错。动画结束后平滑过渡到选牌阶段 |
| 牌背 | 统一设计（星空背面图案），选牌前所有牌随机微动（模拟"活的"感觉） |
| 点击选牌 | 牌背微微上浮（translateY -8px）+ 发光边框（金色 glow），再次点击取消选中 |
| 选牌数量限制 | 最多选 3 张，选满后其余牌变灰不可点击 |
| 位置提示 | 选第 1 张时显示"代表过去"，第 2 张"代表现在"，第 3 张"代表未来" |
| 确认按钮 | 选满 3 张后才亮起，未满时置灰 + 文字"请选 3 张牌" |
| 翻牌动画 | CSS 3D transform，牌绕 Y 轴旋转 180°，时长 0.6s，ease-in-out |
| 音效 | 洗牌音效（阶段一）+ 翻牌音效（阶段三，每张牌翻转时触发） |

#### 设计规范

| 属性 | 值 |
|------|-----|
| 牌背设计 | 深蓝底 + 金色星星几何图案（需设计） |
| 牌面尺寸 | 宽高比 2:3，移动端约 100×150px，最大不超过 140×210px |
| 选中状态 | `box-shadow: 0 0 20px rgba(201,169,110,0.6)` |
| 未选中（选满后） | `opacity: 0.3` |
| 翻牌后牌面 | 显示真实塔罗牌图案（使用免费塔罗牌素材或 CSS 绘制简化版） |

### 4.4 AI 解读页（`/reading`）⭐ 核心体验

#### 页面目标
让用户感觉"被读懂了"——这是灵境最核心的价值交付页面。

#### 页面布局（整体滚动）

```
┌──────────────────────────┐
│                          │
│    🃏    🃏    🃏        │  ← 三张牌缩小显示在顶部
│   过去   现在   未来       │     可点击放大查看
│                          │
│  ──────────────────────  │
│                          │
│  "关于你问的              │
│   「他对我是什么感觉」      │  ← 引用用户的原问题
│   牌面是这样说的..."       │
│                          │
│  ┌──────────────────┐    │
│  │                  │    │
│  │   🔮 AI 解读内容   │    │  ← 核心内容区
│  │                  │    │     逐段显示动画
│  │   （约 300-500 字）│    │     包含三个段落的解读
│  │                  │    │
│  └──────────────────┘    │
│                          │
│  ── 💫 给你的行动建议 ──  │
│                          │
│  🌟 建议一：具体可落地的行动  │
│  🌟 建议二：...            │
│  🌟 建议三：...            │
│                          │
│  ──────────────────────  │
│                          │
│  ┌────────┐ ┌────────┐   │
│  │ 📷 分享 │ │ 💾 保存 │   │  ← 两个操作按钮
│  └────────┘ └────────┘   │
│                          │
│      🔄 再算一次          │  ← 文字链接
│                          │
└──────────────────────────┘
```

#### AI 解读内容结构（规定 AI 输出格式）

```
【整体解读】（100-150字）
- 三张牌的"故事线"——它们如何串联起来回应用户的问题
- 语言风格：温柔但不说废话，像朋友在认真说话
- 必须提及用户的具体问题（不能是泛泛的"你的运势..."）

【过去 · {牌名}】（80-120字）
- 这张牌在"过去"位置的含义
- 与用户问题的关联（必须引用用户问题的关键词）

【现在 · {牌名}】（80-120字）
- 这张牌在"现在"位置的含义
- 当前状态的洞察

【未来 · {牌名}】（80-120字）
- 这张牌在"未来"位置的含义
- 趋势和建议方向
```

#### 行动建议结构

```
3 条具体建议，每条格式：
{emoji} {一句话建议标题}
{2-3 句展开说明，包含可执行的行动}

要求：
- 每条建议必须是用户"明天就可以做的事"
- 不能说"保持积极心态"这种废话
- 要具体到行为：如"明天给他发一条消息，只分享一件今天发生的小事，不问他怎么想"
```

#### 交互规则

| 元素 | 行为 |
|------|------|
| AI 解读内容 | **逐段显示动画**：段落依次淡入（fadeIn + translateY 10px → 0），每段间隔 0.8s，制造"被慢慢解读"的沉浸感。用户可随时滚动阅读已显示的段落 |
| 加载状态 | 翻牌结束→跳转解读页→显示"✨ 牌面正在连接你的心灵..."（loading spinner + 文案），等待 API 返回时显示文案循环变化（3 条轮换："观察牌面中...""聆听你的故事...""解读正在生成..."） |
| 加载超时 | 15 秒未返回 → 显示"牌面能量有点波动，请再试一次" + 重试按钮 |
| API 失败 | 显示友好错误提示 + 重试按钮 + 返回首页链接 |
| 顶部牌面 | 点击可放大查看单张牌的大图 + 牌名 |
| "分享"按钮 | 调用 Web Share API（移动端原生分享）；若不支持则弹出分享海报预览（Canvas 生成图片 → 长按保存）。分享图内容见 4.6。 |
| "保存"按钮 | 保存到 localStorage，按钮变为"✅ 已保存"，2s 后恢复。自动保存逻辑见 4.5。 |
| "再算一次"链接 | 回到 `/ask`，清空之前的问题 |

#### 设计规范

| 属性 | 值 |
|------|-----|
| 解读文字 | `font-size: 16px`, `line-height: 1.8`, 深色背景上浅色文字 `rgba(255,255,255,0.85)` |
| 分隔线 | 金色渐变线，`1px`, `opacity: 0.3` |
| 段落间距 | `margin-bottom: 24px` |
| 行动建议卡片 | 半透金色背景 `rgba(201,169,110,0.1)`，左侧金色竖线 `2px` |

### 4.5 历史记录页（`/history`）

#### 页面目标
让用户看到自己的"心灵轨迹"，建立持续使用的理由。

#### 页面布局

```
┌──────────────────────────┐
│  ← 返回    📜 我的解读记录 │
│                          │
│  ┌──────────────────┐    │
│  │ 🃏 🃏 🃏          │    │
│  │ 2026/06/08 23:15 │    │  ← 每条记录 = 一张卡片
│  │ "他对我是什么感觉" │    │     显示：时间、问题摘要、三张小牌图
│  │                  │    │
│  │        查看 →    │    │
│  └──────────────────┘    │
│                          │
│  ┌──────────────────┐    │
│  │ 🃏 🃏 🃏          │    │
│  │ 2026/06/05 22:40 │    │
│  │ "该不该跳槽"       │    │
│  │        查看 →    │    │
│  └──────────────────┘    │
│                          │
│  [ 清空所有记录 ]         │  ← 底部，红色文字，需二次确认
└──────────────────────────┘
```

#### 生成规则

## 五、AI Prompt 设计规格

> 详细的 Prompt 设计见《08-AI Prompt 设计文档》。此处仅规定 PRD 层面的输出约束。

### 5.1 AI 输出约束

| 约束项 | 规格 |
|--------|------|
| 总字数 | 300-500 字（不含行动建议） |
| 结构 | 【整体解读】→【过去】→【现在】→【未来】→【行动建议】 |
| 语言 | 简体中文，温暖但不说废话，禁止"亲""宝宝""小可爱"等过于亲昵的称呼 |
| 必做 | 必须提及用户问题的具体关键词；必须给出 3 条具体行动建议 |
| 禁止 | 禁止预测生死/疾病/法律问题；禁止绝对化断言（"一定会""绝对不会"）；禁止代替专业心理咨询 |

### 5.2 安全边界

| 场景 | AI 回复策略 |
|------|-----------|
| 用户有自伤/自杀倾向 | 不解读塔罗，温和建议寻求专业帮助，提供心理援助热线 |
| 用户问疾病/法律问题 | "塔罗无法替代专业医生/律师，建议你咨询相关专业人士" |
| 用户问违法/伤害他人 | 拒绝回答，引导正向思考 |
| 用户输入无意义内容 | 友好引导"你似乎还没有写下你的问题哦～" |

## 六、非功能性需求

| 维度 | 要求 |
|------|------|
| **加载速度** | 首页 LCP < 2s，解读 API 响应 < 10s（含 AI 生成时间） |
| **兼容性** | iOS Safari 14+、Android Chrome 90+、微信内置浏览器 |
| **无障碍** | 按钮最小点击区域 44×44px、颜色对比度满足 WCAG AA |
| **隐私** | 用户问题和解读仅存 localStorage，不上传服务器（除 API 调用必需的传输）；API 调用不存储用户问题 |
| **离线** | 静态资源支持 Service Worker 缓存，离线时至少能看历史记录 |
