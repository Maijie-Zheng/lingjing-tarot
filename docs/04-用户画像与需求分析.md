# 灵境 · 用户画像与需求分析

> 文档状态：V1.0 初稿 | 最后更新：2026/06/08 | 作者：@Y9000 + AI协助分析

---

## 一、为什么要做用户画像？

作为 PM，你做每一个功能决策时都会面对一个问题：

> "用户会喜欢这个吗？"

如果你脑子里没有**一个具体的、活生生的人**，你就只能靠猜。用户画像的作用就是把"用户"从"一个模糊的概念"变成"一个你可以替她做决定的人"。

### 怎么做？（小白版指南）

| 方法 | 说明 | 工具 |
|------|------|------|
| **行为观察** | 看目标用户在社交媒体上讨论什么、抱怨什么 | 小红书、抖音评论区 |
| **竞品评论分析** | 看竞品 App 的差评——差评里藏着最真实的需求 | App Store、应用商店 |
| **1v1 访谈** | 找 3-5 个目标用户聊 20 分钟（最值钱的调研） | 微信语音、面对面 |
| **问卷调研** | 量化的需求优先级判断 | 问卷星、腾讯问卷 |

> 💡 **小白提示**：用户画像不是"编一个假人"，而是**基于真实观察提炼出的典型用户模型**。一个好的画像能让你在 3 秒内回答"这个功能她需要吗？"

## 二、用户分层总览

基于前期市场调研，灵境的潜在用户可以分为三层：

| 层级 | 用户类型 | 对塔罗的认知 | 使用频率 | 付费意愿 | 在总用户中占比（估） |
|------|---------|------------|---------|---------|-------------------|
| 🌱 **核心层** | 塔罗好奇者 | 刷到过、感兴趣、没试过 | 低频，触发式 | 低 | ~50% |
| 🌿 **活跃层** | 塔罗使用者 | 用过大众占卜/免费App | 每周1-3次 | 中 | ~35% |
| 🌳 **资深层** | 塔罗爱好者 | 了解牌义、可能找过真人 | 每周3次+ | 高 | ~15% |

**MVP 阶段，灵境的目标用户是：🌱 核心层 + 🌿 活跃层**

> 资深层用户需要复杂牌阵、牌义百科等高级功能，MVP 不服务他们。

## 三、核心用户画像

---

### 画像 A：小雨（核心层代表 🌱）

```
"每次刷到塔罗视频都会停下来看，但又不好意思真的去找人算"
```

| 维度 | 描述 |
|------|------|
| **姓名** | 小雨 |
| **年龄** | 19 岁 |
| **身份** | 大二学生，文科专业 |
| **城市** | 二线城市（长沙/成都/武汉） |
| **月可支配收入** | 1500-2000 元 |
| **常用 App** | 小红书（每天2h+）、抖音、微信、B站 |
| **对 AI 的态度** | 用过 ChatGPT/DeepSeek 写作业，对 AI 不排斥 |

#### 她的一天

```
8:00  起床，刷手机到8:30
10:00 上课，摸鱼刷小红书
12:00 午饭，边吃边刷抖音
14:00 上课 / 自习
18:00 晚饭
20:00 宿舍躺床上刷手机——这是塔罗内容的高频消费时段
22:00 睡前：开始胡思乱想——"他到底喜不喜欢我？""期末考不好怎么办？"
23:00 在焦虑中入睡
```

#### 她的塔罗使用场景

| 触发场景 | 典型问题 | 情绪状态 |
|---------|---------|---------|
| 🌙 深夜独处 | "他对我到底什么感觉？" | 孤独、不确定 |
| 📚 考试前夕 | "这次能过吗？" | 焦虑、寻求安慰 |
| 💬 和朋友聊完感情 | "我们适合在一起吗？" | 纠结、患得患失 |
| 🎓 对未来迷茫 | "我应该考研还是工作？" | 迷茫、需要方向 |
| 📱 刷到别人抽牌 | "我也试试看" | 好奇、FOMO |

#### 她的核心需求

| 表面需求 | 深层需求 |
|---------|---------|
| "想知道他喜不喜欢我" | 需要有个人告诉她"你值得被爱" |
| "这次考试能过吗" | 需要缓解焦虑，获得确定感 |
| "要不要考研" | 需要有人帮她梳理思路，而不是替她做决定 |

#### 她为什么不用现有产品？

| 现有方案 | 为什么不满足 |
|---------|------------|
| 抖音大众占卜 | "是给别人算的，不是给我的"——被动、不精准 |
| 免费塔罗 App | "说的好像都一样"——模板化、不贴心 |
| 真人塔罗师 | "一次 100 多，太贵了，而且不好意思" |

#### 她会怎么发现灵境？

```
朋友在微信发了一张"塔罗解读结果"的分享卡片
→ 看着很好看，点进去
→ 不需要下载App，直接网页就能用
→ 输入自己的问题，抽了三张牌
→ AI给了一段很贴心的解读
→ 她分享了自己的结果卡片到朋友圈
→ 她的另一个朋友看到了，也点进来...
```

### 画像 B：小雯（活跃层代表 🌿）

```
"我会定期看运势、测星座，塔罗是其中一种'了解自己'的方式"
```

| 维度 | 描述 |
|------|------|
| **姓名** | 小雯 |
| **年龄** | 25 岁 |
| **身份** | 互联网公司运营，工作 2 年 |
| **城市** | 一线城市（北京/上海/深圳） |
| **月可支配收入** | 6000-8000 元 |
| **常用 App** | 小红书、微信、测测、得到、小宇宙 |
| **对 AI 的态度** | 工作中常用 AI 工具，对 AI 产品有判断力 |

#### 她的塔罗使用场景

| 触发场景 | 典型问题 | 情绪状态 |
|---------|---------|---------|
| 💼 职场困境 | "我该不该跳槽？" | 犹豫、需要验证 |
| 🤝 人际关系 | "为什么总觉得融入不了？" | 自我怀疑 |
| 💕 感情抉择 | "这段关系还要继续吗？" | 纠结、需要厘清 |
| 🧘 自我探索 | "我最近的状态怎么样？" | 习惯性自省 |

#### 她的核心需求

| 表面需求 | 深层需求 |
|---------|---------|
| "该不该跳槽" | 需要有人帮她分析利弊，而不只是说"相信你的直觉" |
| "最近状态不好" | 需要被看见、被理解，获得具体可操作的建议 |
| "和同事处不好" | 需要一个安全的倾诉对象（AI 比真人更安全） |

#### 她为什么可能用灵境？

- 测测用腻了，达人质量不稳定
- 真人咨询贵，而且不一定比 AI 更"懂"
- 想要**持续的自我记录**，而不只是一次性的解读
- 她愿意为"真正懂我"的解读付费（每月 10-30 元可接受）

#### 她的留存驱动

```
使用灵境 → AI解读很"懂她" → 保存结果
    → 一周后心情不好 → 想起灵境 → 再来一次
    → 发现可以看"历史记录" → 看到自己一个月来的心路历程
    → "这个产品在陪我成长" → 成为忠实用户
```

| **身份** | 大四学生，理工科 |
| **城市** | 一线城市 |
| **月可支配收入** | 2000-3000 元 |
| **常用 App** | B站、知乎、抖音、少数派 |
| **对 AI 的态度** | 非常关注，用过各种 AI 工具 |

#### 他的塔罗使用场景

| 触发场景 | 典型问题 | 情绪状态 |
|---------|---------|---------|
| 🤖 猎奇心理 | "AI 塔罗是什么东西？试试看" | 好奇、技术尝鲜 |
| 🎯 决策辅助 | "offer A 和 offer B 选哪个？" | 理性纠结 |
| 🔍 自我分析 | "我适合做什么方向？" | 探索欲 |

#### 他的核心需求

- 不是"求安慰"，而是"多个视角看问题"
- 对 AI 能力有期待——"你得真的分析出点东西"
- 如果解读太"鸡汤"，他会觉得"没用"并离开

#### 他的价值

> 男性用户在塔罗市场占比从 11%（2019）升到 18%（2026），是增长最快的新人群。虽然 MVP 阶段不优先服务男性用户，但**产品设计上不要排斥男性**——色彩、文案、交互不要过于"女性化"。

## 四、用户需求层次分析

把三个画像的需求汇总，我们发现用户对 AI 塔罗的需求分四个层次：

```
        ┌──────────────────────┐
        │  4. 持续成长陪伴      │  ← "看到自己的变化"（V2+）
        │     (小雯层级)        │
        ├──────────────────────┤
        │  3. 可落地的建议      │  ← "那我该怎么办？"（MVP必备）
        │     (小雨+小雯)       │
        ├──────────────────────┤
        │  2. 被理解的体验      │  ← "它真的读懂我了"（MVP核心）
        │     (所有用户)        │
        ├──────────────────────┤
        │  1. 好玩的仪式感      │  ← "抽牌好好玩！"（MVP基础）
        │     (小雨层级)        │
        └──────────────────────┘
```

| 层次 | 用户需求 | 产品对应 | 优先级 |
|------|---------|---------|--------|
| 1 | 好玩的仪式感 | 翻牌动画、音效、视觉氛围 | **P0** |
| 2 | 被理解的体验 | AI 个性化解读（贴合用户具体问题） | **P0** |
| 3 | 可落地的建议 | 行动建议模块（针对性问题+具体建议） | **P0** |
| 4 | 持续成长陪伴 | 历史记录、心灵轨迹、日记 | **P1**（MVP可做基础版） |

## 五、用户使用场景地图

### 场景 1：深夜焦虑型（最高频）

```
📱 时间：晚上 10:30
🛏️ 地点：床上
😰 情绪：胡思乱想、焦虑、孤独
🗣️ 触发：刚和暧昧对象聊完天，不确定对方什么意思

用户行为路径：
打开灵境 → 输入"他对我到底是什么感觉？"
→ 洗牌动画（仪式感建立） → 选三张牌
→ 翻牌动画（紧张期待感） → AI 解读（"它怎么知道我在想什么？！"）
→ 看行动建议（"好，明天我试试这样"）
→ 截图保存（"留着以后看"）→ 分享给闺蜜（"你看看这个准不准"）
→ 👆 这个分享行为 = 获客
```

### 场景 2：决策纠结型

```
📱 时间：下午 3:00
☕ 地点：咖啡馆 / 工位
🤔 情绪：纠结、需要外部视角
🗣️ 触发：收到两个 offer，不知道怎么选

用户行为路径：
打开灵境 → 输入"offer A和B怎么选？"
→ 抽牌 → AI 解读帮 TA 梳理了选择A和B各自的"牌面意象"
→ 用户不是真的按牌决定，而是借牌"跟自己对话"
→ 行动建议给了具体思考框架 → 用户觉得"被帮助了"
```

### 场景 3：好奇尝鲜型

```
📱 时间：随时
📱 地点：刷手机时
😲 情绪：好奇
🗣️ 触发：朋友发了一张灵境的解读卡片到朋友圈/微信群

用户行为路径：
点击朋友分享的卡片 → 进入灵境
→ "第一次玩"→ 不需要注册 → 直接输入问题
→ 抽牌 → AI 解读 → "挺好玩的" → 也分享了一张卡片
→ 👆 病毒传播完成
```

## 六、用户留存与流失分析

### 用户为什么会再次使用？

| 驱动因素 | 说明 | 产品策略 |
|---------|------|---------|
| 🔁 **情绪触发** | 焦虑/纠结时会"想算一下" | 分享卡片 → 回流入口 |
| 📝 **记录价值** | 想回顾上次的解读 | 本地存储历史记录 |
| 🆕 **新鲜感** | 每次解读不同（AI非模板） | Prompt 确保多样性 |
| 🔔 **被动触达** | "好久没算了，看看" | V2：每日塔罗推送 |

### 用户为什么会流失？

| 流失原因 | 说明 | 预防策略 |
|---------|------|---------|
| 💬 **解读太笼统** | "说的跟星座运势一样，没感觉" | Prompt 必须贴合用户具体问题 |
| 🎲 **仪式感弱** | "就点个按钮，没意思" | 翻牌动画+音效+氛围必须做 |
| 🔄 **一次性的** | "用完就走了，没理由回来" | 分享卡片+历史记录+每日一句 |
| 😕 **不知道问什么** | "我想算但不知道问什么好" | 提供问题引导/示例 |

## 八、关键结论

### 灵境的"一句话用户画像"

> **在深夜感到焦虑或纠结的年轻人，需要一个私密的、懂自己的、有仪式感的方式，帮自己梳理思绪、获得安慰和方向——而不是真的"算命"。**

### MVP 阶段的核心设计原则

| 原则 | 含义 |
|------|------|
| 🎯 **为"深夜的小雨"设计** | 每个功能决策时问：凌晨 11 点躺在床上的小雨会怎么用？ |
| 💬 **解读 > 功能** | 用户来是为了"被理解"，不是为了"用功能"——AI 解读质量是第一优先级 |
| 🎨 **美感本身就是功能** | Labyrinthos 验证了：好看 = 留存 = 传播 |
| 🔗 **分享即获客** | 解读结果必须是可分享的精美卡片，每张卡片 = 一个广告位 |
| 🚫 **不做登录** | 降低首次使用门槛，用本地存储解决记录问题 |
