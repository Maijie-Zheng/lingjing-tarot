## 二、打磨目标

> **从"能跑通"到"好用"——把核心体验从 60 分打磨到 85 分。**

| 维度 | 当前 | 目标 |
|------|------|------|
| 视觉精美度 | 60 分——emoji 代替牌面 | 85 分——经典韦特塔罗真实牌面 |
| 仪式感 | 55 分——9 格选牌太普通 | 85 分——滚动牌轮 + 聚焦放大 + 翻转 |
| 解读体验 | 60 分——文字堆砌 | 80 分——图文并茂 + 直白清晰 |
| 分享传播 | 50 分——微信不可用 | 80 分——微信兜底方案 |

## 三、技术方案

### P0-1 · 真实塔罗牌图片

**现状**：所有牌面显示 🃏 emoji + 文字。

**方案**：
- 使用 Rider-Waite-Smith（韦特塔罗）经典牌面
- 22 张大阿尔卡纳图片来自维基百科公共领域资源
- 放置到 `public/cards/`，按 `{id}.jpg` 命名（`00.jpg` ~ `21.jpg`）
- `TarotCard.jsx` 正面渲染真实图片替代 emoji

**改动文件**：
| 文件 | 改动 |
|------|------|
| `public/cards/` | 🆕 下载 22 张 RWS 牌面图 |
| `src/data/tarotCards.js` | 添加 `image` 字段 |
| `src/components/TarotCard.jsx` | 正面显示图片 |

---

### P0-2 · 问题引导优化

**现状**：8 条固定问题，页面加载时随机选 5 条，无法刷新。

**方案**：
- 问题库扩充到 20 条
- 添加「🔄 换一批」按钮，点击随机换 5 条
- 切换时 chip 淡入动画

**改动文件**：
| 文件 | 改动 |
|------|------|
| `src/pages/AskPage.jsx` | 添加刷新按钮 + 扩充问题库 |

---

### P0-3 · 抽牌交互重做（核心）

**现状**：9 张牌背 3×3 网格，点击选中。参与感弱。

**方案**：水平滚动牌轮

```
交互流程：
┌─────────────────────────────────┐
│  [小牌] [中牌] [🔍大牌] [中牌] [小牌]  │  ← 22张牌水平滚动
│                  ↑ 聚焦放大          │
│            点击 → 3D翻转 → 飞到右侧   │
│                                  │
│  已选区：[牌1] [牌2] [ ？]         │  ← 选中的牌依次排列
└─────────────────────────────────┘
```

关键交互：
1. 22 张牌水平排列，支持手指滑动 + 自动吸附到最近牌
2. 正中央的牌放大到 1.3x + 金色光晕，两侧逐渐缩小变暗
3. 点击中间聚焦牌 → 3D 翻转 → 牌飞到顶部已选区
4. 重复 3 次 → 自动进入翻牌揭示阶段
5. 保留 30% 概率逆位随机

**改动文件**：
| 文件 | 改动 |
|------|------|
| `src/components/CardCarousel.jsx` | 🆕 牌轮滚动组件 |
| `src/pages/ShufflePage.jsx` | 重写阶段 1&2 |
| `src/components/TarotCard.jsx` | 可能微调尺寸/发光 |

---

### P0-4 · 解读页视觉升级

**现状**：顶部小牌缩略图（看不清），纯文字堆砌。AI 输出太含蓄绕弯子。

**方案**：
- 牌面展示：三张牌用大号 `TarotCard` 展示完整牌面图
- 图文并茂：每个解读段落（过去/现在/未来）旁配对应牌面图
- Prompt 调优：要求 AI「用简洁清晰的中文，少用比喻，直接说重点」

**改动文件**：
| 文件 | 改动 |
|------|------|
| `src/pages/ReadingPage.jsx` | 布局重做，牌面+文字并排 |
| `src/utils/promptBuilder.js` | System Prompt 调优 |

---

### P0-5 · 分享卡片微信兼容

**现状**：Canvas 生成 PNG → Web Share API。微信浏览器两者都不支持。

**方案**：双轨策略
1. **主方案**（保留）：Canvas 生成 PNG → Web Share API / 下载
2. **微信兜底**（新增）：检测微信浏览器 → 渲染 HTML 卡片弹窗 → 提示「截图保存」
3. HTML 卡片设计为 3:4 竖版，紫色星空背景 + 牌面 + 精选片段 + 品牌

**改动文件**：
| 文件 | 改动 |
|------|------|
| `src/components/ShareCardHTML.jsx` | 🆕 HTML 截图卡片组件 |
| `src/pages/ReadingPage.jsx` | 分享逻辑加微信浏览器判断 |

## 五、执行顺序

```
P0-1 牌面图片 → P0-2 问题引导 → P0-3 牌轮抽牌 → P0-4 解读升级 → P0-5 分享修复
   (基础设施)     (小改动热身)      (核心大改)       (依赖牌面图)     (独立)
```

每轮完成后：
1. 本地 `npm run dev` 验证
2. Git commit 到 `phase2-polish` 分支
3. 真机测试（手机访问本地或 Vercel Preview）
